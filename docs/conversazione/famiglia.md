# La famiglia

Parlare dei propri familiari: fratelli, sorelle, cosa fanno e dove vivono.

Talking about your family members: brothers, sisters, what they do and where they live.
{: .en }

| Domanda | Come rispondere |
| --- | --- |
| Hai fratelli o sorelle? *Do you have any brothers or sisters?*{ .en } | Ho … fratelli e … sorelle. / Sono figlio/a unico/a. *I have … brothers and … sisters. / I'm an only child.*{ .en } |
| Come si chiama tuo fratello? *What's your brother's name?*{ .en } | Mio fratello si chiama … *My brother's name is …*{ .en } |
| Dove vive tuo fratello? *Where does your brother live?*{ .en } | Mio fratello vive a … *My brother lives in …*{ .en } |
| Quanti anni ha tuo fratello? *How old is your brother?*{ .en } | Ha … anni. *He's … years old.*{ .en } |
| Tuo fratello studia o lavora? *Does your brother study or work?*{ .en } | Studia … / Lavora, fa … *He studies … / He works, he's a …*{ .en } |
| Quali sono i tuoi hobby? *What are your hobbies?*{ .en } | I miei hobby sono … *My hobbies are …*{ .en } |

!!! tip "Suggerimento"
    Con i nomi di famiglia al singolare l'articolo si omette: *mio fratello*, *mia sorella*. Al plurale invece si usa: *i miei fratelli*, *le mie sorelle*.

    With singular family nouns the article is left out: *mio fratello*, *mia sorella*. In the plural, however, it is used: *i miei fratelli*, *le mie sorelle*.
    {: .en }

Per le forme *ha*, *vive*, *lavora* vedi il [presente indicativo](../grammatica/presente-indicativo.md).

For the forms *ha*, *vive*, *lavora* see the [present indicative](../grammatica/presente-indicativo.md).
