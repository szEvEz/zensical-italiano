# L'amicizia

Domande per parlare degli amici e del significato dell'amicizia. Non ci sono risposte fisse: rispondi con le tue esperienze.

Questions for talking about friends and what friendship means. There are no set answers: answer from your own experience.
{: .en }

## Domande

1. Hai un migliore amico o una migliore amica? *Do you have a best friend?*{ .en }
2. Come si chiama? *What's their name?*{ .en }
3. Da quanto tempo siete amici? *How long have you been friends?*{ .en }
4. Dove hai conosciuto il tuo amico / la tua amica? *Where did you meet your friend?*{ .en }
5. Cosa fai di solito con i tuoi amici? *What do you usually do with your friends?*{ .en }
6. Quanto spesso vedi i tuoi amici? *How often do you see your friends?*{ .en }
7. Preferisci avere molti amici o pochi ma buoni? *Do you prefer having lots of friends or just a few good ones?*{ .en }
8. Cosa ti piace dei tuoi amici? *What do you like about your friends?*{ .en }
9. Aiuti i tuoi amici quando hanno un problema? *Do you help your friends when they have a problem?*{ .en }
10. È importante per te l'amicizia? Perché? *Is friendship important to you? Why?*{ .en }

!!! tip "Suggerimento"
    Una frase che descrive bene un'amicizia vera: *"Io ci sono per loro, loro ci sono per me."*

    A sentence that describes true friendship well: *"I'm there for them, they're there for me."*
    {: .en }

    Altre frasi utili:

    Other useful phrases:
    {: .en }

    - *"Siamo amici da … anni."* *"We've been friends for … years."*{ .en }
    - *"Ci vediamo una volta alla settimana."* *"We see each other once a week."*{ .en }
    - *"Preferisco pochi amici ma buoni."* *"I prefer a few good friends."*{ .en }
