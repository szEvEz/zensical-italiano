# Presentarsi

Le prime domande che senti quando conosci qualcuno. Esercitati a rispondere in modo naturale.

The first questions you hear when you meet someone. Practise answering naturally.
{: .en }

| Domanda | Come rispondere |
| --- | --- |
| Come ti chiami? *What's your name?*{ .en } | Mi chiamo … *My name is …*{ .en } |
| Dove vivi? *Where do you live?*{ .en } | Vivo a …, in … *I live in …, in …*{ .en } |
| Che fai nella vita? (studi o lavori?) *What do you do? (Do you study or work?)*{ .en } | Studio … / Lavoro … *I study … / I work …*{ .en } |
| Quanti anni hai? *How old are you?*{ .en } | Ho … anni. *I'm … years old.*{ .en } |
| Perché vuoi imparare l'italiano? *Why do you want to learn Italian?*{ .en } | Perché … *Because …*{ .en } |

!!! tip "Suggerimento"
    Ogni risposta si può adattare a te: cambia il nome, la città, il lavoro e l'età con i tuoi dati. Per esempio: *"Mi chiamo …, vivo a …, studio/lavoro …, ho … anni."*

    You can adapt every answer to yourself: replace the name, city, job and age with your own details. For example: *"My name is …, I live in …, I study/work …, I'm … years old."*
    {: .en }

Per rivedere le forme dei verbi (mi chiamo, vivo, lavoro, voglio), vedi il [presente indicativo](../grammatica/presente-indicativo.md).

To review the verb forms (mi chiamo, vivo, lavoro, voglio), see the [present indicative](../grammatica/presente-indicativo.md).
{: .en }
