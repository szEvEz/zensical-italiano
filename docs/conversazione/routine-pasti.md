# La routine e i pasti

Parlare della giornata tipica: cosa mangi, a che ora fai le cose.

Talking about your typical day: what you eat and what time you do things.
{: .en }

| Domanda | Come rispondere |
| --- | --- |
| Che cosa mangi normalmente a colazione? *What do you usually have for breakfast?*{ .en } | A colazione mangio … e bevo … *For breakfast I eat … and drink …*{ .en } |
| A che ora fai colazione? *What time do you have breakfast?*{ .en } | Faccio colazione alle … *I have breakfast at …*{ .en } |
| Che cosa mangi normalmente a pranzo? *What do you usually have for lunch?*{ .en } | A pranzo mangio … *For lunch I eat …*{ .en } |
| A che ora pranzi? *What time do you have lunch?*{ .en } | Pranzo alle … *I have lunch at …*{ .en } |
| Che cosa mangi normalmente a cena? *What do you usually have for dinner?*{ .en } | A cena mangio … *For dinner I eat …*{ .en } |
| A che ora ceni? *What time do you have dinner?*{ .en } | Ceno alle … *I have dinner at …*{ .en } |
| A che ora ti svegli la mattina? *What time do you wake up in the morning?*{ .en } | Mi sveglio alle … *I wake up at …*{ .en } |
| A che ora vai a dormire? *What time do you go to bed?*{ .en } | Vado a dormire alle … *I go to bed at …*{ .en } |

!!! tip "Suggerimento"
    Per dire l'ora si usa *alle* + numero (*alle sette*, *alle venti*), ma con l'una si dice *all'una*. Vedi [dire l'ora](../lessico/ora.md).

    To say the time you use *alle* + number (*alle sette* = at seven, *alle venti* = at eight p.m.), but with one o'clock you say *all'una*. See [telling the time](../lessico/ora.md).
    {: .en }

I verbi *svegliarsi* (mi sveglio) sono riflessivi. Per le altre forme vedi il [presente indicativo](../grammatica/presente-indicativo.md).

Verbs like *svegliarsi* (mi sveglio) are reflexive. For the other forms see the [present indicative](../grammatica/presente-indicativo.md).
{: .en }
