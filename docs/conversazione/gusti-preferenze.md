# Gusti e preferenze

Come parlare delle cose che preferisci: colori, cibo, città.

How to talk about the things you prefer: colours, food, cities.
{: .en }

| Domanda | Come rispondere |
| --- | --- |
| Qual è il tuo colore preferito? *What's your favourite colour?*{ .en } | Il mio colore preferito è … *My favourite colour is …*{ .en } |
| Qual è il tuo piatto preferito? *What's your favourite dish?*{ .en } | Il mio piatto preferito è … *My favourite dish is …*{ .en } |
| Qual è la tua città preferita? *What's your favourite city?*{ .en } | La mia città preferita è … *My favourite city is …*{ .en } |

!!! tip "Suggerimento"
    Nota il modello: **"Qual è …? Il mio / La mia … preferito/a è …"**

    Note the pattern: **"Qual è …? Il mio / La mia … preferito/a è …"** (What's …? My favourite … is …)
    {: .en }

    L'aggettivo *preferito* concorda con il nome: *il colore preferit**o***, *la città preferit**a***. E ricorda: *qual è* si scrive senza apostrofo.

    The adjective *preferito* agrees with the noun: *il colore preferit**o***, *la città preferit**a***. And remember: *qual è* is written without an apostrophe.
    {: .en }
