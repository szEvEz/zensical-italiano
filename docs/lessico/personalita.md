# Gli aggettivi di personalità

Questi aggettivi descrivono il **carattere** di una persona. Per ognuno trovi il significato e un breve esempio.

These adjectives describe a person's **character**. For each one you'll find its meaning and a short example.
{: .en }

| Aggettivo | Significato ed esempio |
|------------|--------------------------|
| generoso | dà volentieri agli altri — *Luca è generoso: offre sempre il caffè.* *generous: gives willingly to others — Luca is generous: he always pays for the coffee.*{ .en } |
| altruista | pensa al bene degli altri — *Anna è altruista: aiuta chi è in difficoltà.* *selfless: thinks of others' well-being — Anna is selfless: she helps people in difficulty.*{ .en } |
| divertente | fa ridere — *Marco è divertente: racconta barzellette.* *funny: makes people laugh — Marco is funny: he tells jokes.*{ .en } |
| timido | si vergogna facilmente — *Sara è timida: parla poco con gli sconosciuti.* *shy: gets embarrassed easily — Sara is shy: she doesn't talk much with strangers.*{ .en } |
| silenzioso | parla poco — *Il nonno è silenzioso: ascolta più che parlare.* *quiet: doesn't talk much — Grandpa is quiet: he listens more than he talks.*{ .en } |
| introverso | preferisce stare da solo — *Paolo è introverso: ama leggere in casa.* *introverted: prefers being alone — Paolo is introverted: he loves reading at home.*{ .en } |
| studioso | ama studiare — *Giulia è studiosa: legge ogni giorno.* *studious: loves studying — Giulia is studious: she reads every day.*{ .en } |
| irascibile | si arrabbia facilmente — *Paolo è **irascibile**: si arrabbia facilmente.* *short-tempered: gets angry easily — Paolo is short-tempered: he gets angry easily.*{ .en } |
| socievole | sta volentieri con gli altri — *Elena è socievole: ha molti amici.* *sociable: likes being with others — Elena is sociable: she has lots of friends.*{ .en } |
| estroverso | aperto e comunicativo — *Davide è estroverso: parla con tutti.* *extroverted: open and communicative — Davide is extroverted: he talks to everyone.*{ .en } |
| amichevole | gentile e cordiale — *Il vicino è amichevole: saluta sempre.* *friendly: kind and warm — The neighbour is friendly: he always says hello.*{ .en } |
| pigro | non ama fare fatica — *Il gatto è pigro: dorme tutto il giorno.* *lazy: doesn't like making an effort — The cat is lazy: it sleeps all day.*{ .en } |
| puntuale | arriva sempre in orario — *Marta è puntuale: non è mai in ritardo.* *punctual: always arrives on time — Marta is punctual: she's never late.*{ .en } |
| preciso | fa le cose con attenzione — *L'ingegnere è preciso nei calcoli.* *precise: does things carefully — The engineer is precise in his calculations.*{ .en } |
| creativo | ha molte idee nuove — *L'artista è creativo: inventa storie.* *creative: has lots of new ideas — The artist is creative: he makes up stories.*{ .en } |
| gentile | educato e cortese — *La maestra è gentile con i bambini.* *kind: polite and courteous — The teacher is kind to the children.*{ .en } |
| simpatico | piacevole da conoscere — *Il tuo amico è simpatico: mi piace.* *nice, likeable: pleasant to get to know — Your friend is nice: I like him.*{ .en } |
| sincero | dice sempre la verità — *Franco è sincero: non mente mai.* *honest: always tells the truth — Franco is honest: he never lies.*{ .en } |
| coraggioso | non ha paura — *Il pompiere è coraggioso.* *brave: isn't afraid — The firefighter is brave.*{ .en } |
| scherzoso | ama scherzare — *Il papà è scherzoso: fa sempre battute.* *playful: loves joking — Dad is playful: he's always cracking jokes.*{ .en } |
| ordinato | tiene tutto in ordine — *Lucia è ordinata: la sua scrivania è pulita.* *tidy: keeps everything in order — Lucia is tidy: her desk is clean.*{ .en } |
| egoista | pensa solo a sé — *Non essere egoista: condividi con gli altri.* *selfish: thinks only of himself — Don't be selfish: share with others.*{ .en } |
| intelligente | capisce in fretta — *Il bambino è intelligente: impara subito.* *intelligent: understands quickly — The child is intelligent: he learns straight away.*{ .en } |
| sveglio | vispo e reattivo — *Quel ragazzo è sveglio: risolve tutto in fretta.* *sharp, bright: lively and quick — That boy is sharp: he solves everything quickly.*{ .en } |
| sportivo | ama lo sport — *Mia sorella è sportiva: corre ogni mattina.* *sporty: loves sport — My sister is sporty: she runs every morning.*{ .en } |
| allegro | di buon umore — *Il nonno è allegro: sorride sempre.* *cheerful: in a good mood — Grandpa is cheerful: he's always smiling.*{ .en } |
| maleducato | senza buone maniere — *È maleducato: non saluta mai.* *rude: has no manners — He's rude: he never says hello.*{ .en } |
| paziente | sa aspettare con calma — *La maestra è paziente con gli alunni.* *patient: can wait calmly — The teacher is patient with the pupils.*{ .en } |
| insicuro | dubita di sé — *Sono insicuro prima di un esame.* *insecure, unsure: doubts himself — I feel unsure of myself before an exam.*{ .en } |
| debole | senza forza — *Dopo l'influenza mi sento debole.* *weak: without strength — After the flu I feel weak.*{ .en } |
| loquace | parla molto — *La zia è loquace: chiacchiera per ore.* *talkative: talks a lot — My aunt is talkative: she chats for hours.*{ .en } |
| sensibile | prova emozioni intense — *Elena è sensibile: si commuove facilmente.* *sensitive: feels emotions intensely — Elena is sensitive: she's easily moved.*{ .en } |
| permaloso | si offende per poco — *Non fare battute: è permaloso.* *touchy: takes offence easily — Don't make jokes: he's touchy.*{ .en } |
| deciso | sa cosa vuole — *Il capo è deciso: prende scelte rapide.* *decisive: knows what he wants — The boss is decisive: he makes quick choices.*{ .en } |

!!! note "Nota"
    Ricorda l'accordo: *Luca è generos**o***, *Anna è generos**a***. Gli aggettivi in **-e** (gentile, intelligente) e alcuni come **altruista**, **egoista** restano uguali al singolare per maschile e femminile.
    *Remember the agreement: **Luca è generoso**, **Anna è generosa**. Adjectives ending in **-e** (**gentile**, **intelligente**) and some others such as **altruista** and **egoista** stay the same in the singular for masculine and feminine.*{ .en }

!!! tip "Trucco"
    Molte coppie sono opposti: **introverso ↔ estroverso**, **generoso ↔ egoista**, **timido ↔ socievole**, **paziente ↔ irascibile**.
    *Many pairs are opposites: **introverso ↔ estroverso** (introverted ↔ extroverted), **generoso ↔ egoista** (generous ↔ selfish), **timido ↔ socievole** (shy ↔ sociable), **paziente ↔ irascibile** (patient ↔ short-tempered).*{ .en }

## Esercizi

1. Trova il contrario: *egoista*, *timido*, *pigro*. *Find the opposite: **egoista**, **timido**, **pigro**.*{ .en }
2. Completa: "Marta arriva sempre in orario, è molto ___." *Complete: "Marta always arrives on time, she is very ___."*{ .en }
3. Descrivi un amico con tre aggettivi. *Describe a friend with three adjectives.*{ .en }

??? success "Soluzioni"
    1. egoista ↔ **generoso/altruista**; timido ↔ **socievole/estroverso**; pigro ↔ **attivo/sportivo**.
    2. Marta arriva sempre in orario, è molto **puntuale**.
    3. Risposta libera, ad esempio: "Il mio amico è simpatico, generoso e divertente."
