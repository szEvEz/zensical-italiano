# Gli animali

Ogni animale è descritto con **un aggettivo**. Fai attenzione all'accordo (maschile/femminile) tra il nome e l'aggettivo!
*Each animal is described with **one adjective**. Pay attention to the agreement (masculine/feminine) between the noun and the adjective!*{ .en }

| Animale | Descrizione |
|----------|--------------|
| il cavallo | è veloce (fast) |
| il pesce | è piccolo (small) |
| il gatto | è indipendente (independent) |
| la volpe | è intelligente (clever) |
| la tartaruga | è lenta (slow) |
| il lupo | è morbido (soft) |
| il delfino | è socievole (sociable) |
| il cane | è amichevole (friendly) |
| lo squalo | è aggressivo (aggressive) |
| il leone | è il re (the king) |
| la pecora | è calma (calm) |
| la scimmia | è divertente (funny) |
| l'elefante | è grande (big) |
| il serpente | è velenoso (venomous) |
| la capra | è erbivora (herbivorous) |
| l'orso | è goloso (greedy, has a sweet tooth) |
| il coccodrillo | è aggressivo (aggressive) |
| il coniglio | è dolce (sweet, gentle) |
| la mucca | è gentile (gentle, kind) |
| il toro | è arrabbiato (angry) |
| la zebra | è a strisce (striped) |
| l'uccello | è rumoroso (noisy, loud) |
| il ragno | è disgustoso (disgusting) |
| la giraffa | è alta (tall) |

!!! note "Nota — l'accordo dell'aggettivo"
    L'aggettivo cambia in base al genere del nome:
    *The adjective changes according to the gender of the noun:*{ .en }

    - la pecora è calm**a** / il gatto è calm**o** *the sheep is calm / the cat is calm*{ .en }
    - la volpe è intelligent**e** / il cane è intelligent**e** (gli aggettivi in **-e** non cambiano al singolare) *the fox is clever / the dog is clever (adjectives ending in **-e** don't change in the singular)*{ .en }

!!! tip "Trucco"
    Nota gli articoli particolari: **lo** squalo (davanti a *s* + consonante), **l'**elefante, **l'**orso, **l'**uccello (davanti a vocale).
    *Note the special articles: **lo squalo** (before **s** + consonant), **l'elefante**, **l'orso**, **l'uccello** (before a vowel).*{ .en }

## Esercizi

1. Completa con l'aggettivo giusto: "La tartaruga è ___ (lento)." *Complete with the correct adjective: "The tortoise is ___ (slow)."*{ .en }
2. Qual è "il re" degli animali? *Which animal is "the king" of the animals?*{ .en }
3. Scegli un animale e descrivilo con un aggettivo diverso da quello della tabella. *Choose an animal and describe it with a different adjective from the one in the table.*{ .en }

??? success "Soluzioni"
    1. La tartaruga è **lenta**.
    2. Il leone.
    3. Risposta libera, ad esempio: "Il gatto è **pigro**."
