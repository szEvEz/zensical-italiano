# Gli avverbi di frequenza

Gli **avverbi di frequenza** dicono *quanto spesso* facciamo qualcosa.
***Adverbs of frequency** tell us how often we do something.*{ .en }

| Avverbio | Inglese | Frequenza |
|-----------|-----------|------------|
| sempre | always | 100% |
| spesso | often | ~75% |
| qualche volta | sometimes | ~50% |
| raramente | rarely | ~20% |
| mai | never | 0% |

## Posizione nella frase

Di solito l'avverbio va **dopo il verbo**:
*The adverb usually goes **after the verb**:*{ .en }

- Bevo **sempre** un caffè la mattina. *I always have a coffee in the morning.*{ .en }
- Vado **spesso** in palestra. *I often go to the gym.*{ .en }
- **Qualche volta** guardo un film. *(può stare anche all'inizio)* *Sometimes I watch a film. (it can also go at the beginning)*{ .en }
- Leggo **raramente** il giornale. *I rarely read the newspaper.*{ .en }

!!! note "Nota — «non … mai» (doppia negazione)"
    Con **mai** in italiano si usa la **doppia negazione**: **non** prima del verbo e **mai** dopo.
    *With **mai**, Italian uses a **double negative**: **non** before the verb and **mai** after it.*{ .en }

    - Io **non** arrivo **mai** in ritardo a lavoro. *I'm never late for work.*{ .en }
    - **Non** bevo **mai** alcolici. *I never drink alcohol.*{ .en }

    In inglese basta una negazione (*I'm **never** late*), ma in italiano servono entrambe: **non … mai**.
    *In English one negative is enough ("I'm never late"), but Italian needs both: **non … mai**.*{ .en }

## Altri esempi

- Sfortunatamente lavoro **sempre** per molte ore al computer. *Unfortunately I always work for many hours at the computer.*{ .en }
- Io **non** arrivo **mai** in ritardo a lavoro. *I'm never late for work.*{ .en }
- Il sabato **qualche volta** dormo fino a tardi. *On Saturdays I sometimes sleep in.*{ .en }

!!! tip "Trucco"
    L'unico avverbio che richiede **non** davanti al verbo è **mai**. Gli altri (sempre, spesso, raramente…) no.
    *The only adverb that requires **non** before the verb is **mai**. The others (**sempre**, **spesso**, **raramente**…) don't.*{ .en }

## Esercizio — Rispondi ad alta voce

Rispondi a ogni domanda usando un avverbio di frequenza (*sempre, spesso, qualche volta, raramente, mai*). Non ci sono risposte fisse: parla di te!

Answer each question using an adverb of frequency (**sempre**, **spesso**, **qualche volta**, **raramente**, **mai**). There are no fixed answers: talk about yourself!
{: .en }

1. Fai colazione? *Do you have breakfast?*{ .en }
2. Fai sport? *Do you do sport?*{ .en }
3. Guardi la TV la sera? *Do you watch TV in the evening?*{ .en }
4. Vai in palestra? *Do you go to the gym?*{ .en }
5. Bevi caffè? *Do you drink coffee?*{ .en }
6. Leggi libri? *Do you read books?*{ .en }
7. Viaggi? *Do you travel?*{ .en }
8. Cucini la sera? *Do you cook in the evening?*{ .en }
9. Vai a dormire tardi? *Do you go to bed late?*{ .en }
10. Ti rilassi? *Do you relax?*{ .en }

!!! note "Nota"
    Esempi di risposta: "**Faccio sempre** colazione." / "**Non vado mai** in palestra." / "**Qualche volta** leggo libri la sera."
    *Sample answers: "I always have breakfast." / "I never go to the gym." / "Sometimes I read books in the evening."*{ .en }
