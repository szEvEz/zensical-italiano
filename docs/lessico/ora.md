# Dire l'ora

Per chiedere l'ora puoi dire:
*To ask the time you can say:*{ .en }

- **Che ore sono?** (What time is it?)
- **Che ora è?** (stessa domanda, al singolare) *(the same question, in the singular)*{ .en }

## Esempi

| Ora | Come si dice |
|------|----------------|
| 9:43 | Sono le nove e quarantatré. *It's nine forty-three.*{ .en } |
| 10:30 | Sono le dieci e mezza (o: e trenta). *It's half past ten (or: ten thirty).*{ .en } |
| 5:00 | Sono le cinque. *It's five o'clock.*{ .en } |
| 19:00 | Sono le diciannove. / Sono le sette (di sera). *It's nineteen hundred. / It's seven (in the evening).*{ .en } |
| 12:00 | È mezzogiorno. *It's midday.*{ .en } |
| 24:00 / 00:00 | È mezzanotte. *It's midnight.*{ .en } |
| 1:00 | È l'una. *It's one o'clock.*{ .en } |

!!! note "Nota — «è» o «sono le»?"
    Si usa il **singolare** con:
    *The **singular** is used with:*{ .en }

    - **È** l'una. *It's one o'clock.*{ .en }
    - **È** mezzogiorno. *It's midday.*{ .en }
    - **È** mezzanotte. *It's midnight.*{ .en }

    In tutti gli altri casi si usa il **plurale**: **Sono le** due, **Sono le** dieci e mezza…
    *In all other cases the **plural** is used: **Sono le** due (it's two o'clock), **Sono le** dieci e mezza (it's half past ten)…*{ .en }

!!! tip "Trucco"
    - **e mezza / e mezzo** = :30 *half past*{ .en }
    - **e un quarto** = :15 *quarter past*{ .en }
    - **meno un quarto** = :45 (Es. *le otto meno un quarto* = 7:45) *quarter to (e.g. **le otto meno un quarto** = quarter to eight)*{ .en }

## A che ora…?

Per chiedere l'orario di un evento usa **a che ora**:
*To ask what time something happens, use **a che ora** (at what time):*{ .en }

- **A che ora** apre il negozio? — Apre **alle** nove. *What time does the shop open? — It opens at nine.*{ .en }
- **A che ora** ti alzi? — Mi alzo **alle** sette. *What time do you get up? — I get up at seven.*{ .en }
- **A che ora** è la lezione? — **All'**una. / **A** mezzogiorno. *What time is the lesson? — At one. / At midday.*{ .en }

!!! note "Nota"
    Con l'orario usa **alle** (alle otto), ma **all'una**, **a** mezzogiorno, **a** mezzanotte.
    *With clock times use **alle** (**alle otto**, at eight), but **all'una** (at one), **a mezzogiorno** (at midday), **a mezzanotte** (at midnight).*{ .en }

## Esercizi

1. Scrivi in parole: 8:00, 1:00, 12:00. *Write in words: 8:00, 1:00, 12:00.*{ .en }
2. Completa: "___ ora è? — ___ l'una." *Complete: "___ time is it? — ___ one o'clock."*{ .en }
3. Rispondi: "A che ora fai colazione?" *Answer: "What time do you have breakfast?"*{ .en }

??? success "Soluzioni"
    1. Sono le otto; È l'una; È mezzogiorno (12:00 di giorno) / È mezzanotte (00:00).
    2. **Che** ora è? — **È** l'una.
    3. Risposta libera, ad esempio: "Faccio colazione **alle** sette e mezza."
