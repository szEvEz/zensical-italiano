# Le emozioni

Per parlare di come stai, usa l'espressione **Mi sento…** (I feel…) seguita da un aggettivo.
*To talk about how you feel, use the expression **Mi sento…** (I feel…) followed by an adjective.*{ .en }

| Mi sento… | Inglese |
|------------|-----------|
| felice | happy |
| triste | sad |
| arrabbiato/a | angry |
| tranquillo/a | calm |
| preoccupato/a | worried |
| entusiasta | enthusiastic |
| stanco/a | tired |
| rilassato/a | relaxed |
| nervoso/a | nervous |
| orgoglioso/a | proud |
| deluso/a | disappointed |
| curioso/a | curious |
| spaventato/a | scared |
| soddisfatto/a | satisfied |
| confuso/a | confused |
| emozionato/a | excited |
| annoiato/a | bored |
| sollevato/a | relieved |
| grato/a | grateful |
| fiducioso/a | confident, hopeful |

!!! note "Nota — l'accordo -o / -a"
    Molti aggettivi cambiano la vocale finale in base al genere di chi parla:
    *Many adjectives change their final vowel according to the gender of the speaker:*{ .en }

    - Un uomo dice: *Mi sento stanc**o**, arrabbiat**o**, grat**o**.* *A man says: "I feel tired, angry, grateful."*{ .en }
    - Una donna dice: *Mi sento stanc**a**, arrabbiat**a**, grat**a**.* *A woman says: "I feel tired, angry, grateful."*{ .en }

    Gli aggettivi in **-e** come **felice**, **triste** ed **entusiasta** restano uguali per maschile e femminile.
    *Adjectives ending in **-e** such as **felice** and **triste**, as well as **entusiasta**, stay the same for masculine and feminine.*{ .en }

!!! tip "Trucco"
    Puoi aggiungere un motivo con **perché**: *Mi sento felice **perché** oggi è sabato.*
    *You can add a reason with **perché** (because): "I feel happy because today is Saturday."*{ .en }

## Esercizi

1. Come ti senti oggi? Rispondi con "Mi sento…". *How do you feel today? Answer with **Mi sento…**.*{ .en }
2. Completa (per una donna): "Mi sento stanc__ e nervos__." *Complete (for a woman): "I feel tired and nervous."*{ .en }
3. Qual è il contrario di *triste*? *What is the opposite of **triste**?*{ .en }

??? success "Soluzioni"
    1. Risposta libera, ad esempio: "Mi sento rilassato/a perché è domenica."
    2. Mi sento stanc**a** e nervos**a**.
    3. **felice** (o *contento/a*).
