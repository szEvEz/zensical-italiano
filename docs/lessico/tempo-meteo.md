# Il tempo (meteo)

Per chiedere che tempo fa si dice:
*To ask what the weather is like, you say:*{ .en }

- **Com'è il tempo?** (What's the weather like?)
- **Che tempo fa?** *(same question: What's the weather like?)*{ .en }

## Vocabolario

| Italiano | Inglese / spiegazione |
|-----------|-------------------------|
| Il tempo è bello. | The weather is nice. |
| Il tempo è brutto. | The weather is bad. |
| Il tempo è buono. | The weather is good. |
| Il tempo è cattivo. | The weather is bad (literally: "wicked"). |
| C'è il sole. (è soleggiato) | The sun is shining. (sunny) |
| Ci sono le nuvole. (è nuvoloso) | It's cloudy. |
| C'è la pioggia. (piove) | It's raining. |
| C'è la neve. (nevica) | It's snowing. |
| Fa caldo. | It's warm/hot. |
| Fa freddo. | It's cold. |

!!! note "Nota"
    - **C'è** + singolare (c'è il sole, c'è la neve), **ci sono** + plurale (ci sono le nuvole). *Use **c'è** (there is) + singular (**c'è il sole**, **c'è la neve**), **ci sono** (there are) + plural (**ci sono le nuvole**).*{ .en }
    - **Piove**, **nevica** sono verbi impersonali: si usano solo alla terza persona singolare. *The verbs **piove** (it rains) and **nevica** (it snows) are impersonal: they are only used in the third person singular.*{ .en }
    - Per la temperatura si usa **fa**: *fa caldo*, *fa freddo*, *fa fresco*. *For temperature, use **fa**: **fa caldo** (it's hot), **fa freddo** (it's cold), **fa fresco** (it's cool).*{ .en }

!!! tip "Trucco"
    Puoi collegare il tempo alla stagione: *In inverno fa freddo e a volte nevica. In estate fa caldo e c'è il sole.*
    *You can link the weather to the season: "In winter it's cold and sometimes it snows. In summer it's hot and sunny."*{ .en }

## Esercizi

1. Traduci: "It's raining and it's cold."
2. Completa: "___ le nuvole, è nuvoloso."
3. Rispondi: "Com'è il tempo oggi?" *Answer: "What's the weather like today?"*{ .en }

??? success "Soluzioni"
    1. Piove e fa freddo. / C'è la pioggia e fa freddo.
    2. **Ci sono** le nuvole, è nuvoloso.
    3. Risposta libera, ad esempio: "Oggi il tempo è bello, c'è il sole e fa caldo."
