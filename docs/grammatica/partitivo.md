# Articolo partitivo

L'**articolo partitivo** si forma con **di + articolo determinativo** (*del, dello,
della*…) e indica una **quantità non precisa**: corrisponde all'inglese *some* (o
*any* nelle domande). Al singolare si usa con le cose che non si contano (*del pane*,
*dell'acqua*); al plurale è il plurale dell'articolo indeterminativo (*un libro* →
*dei libri*).

The **partitive article** is formed with **di + definite article** (**del, dello,
della**…) and expresses an **unspecified quantity**: it corresponds to English *some*
(or *any* in questions). In the singular it is used with things you can't count
(**del pane**, **dell'acqua**); in the plural it is the plural of the indefinite
article (**un libro** → **dei libri**).
{: .en }

## Come si forma

Le forme sono le stesse della preposizione articolata con *di* (vedi
[Preposizioni](preposizioni.md)). Per scegliere la forma giusta valgono le regole
degli [articoli](articoli.md): *lo* davanti a s + consonante, z, gn, ps…; *l'*
davanti a vocale.

The forms are the same as the articulated preposition with **di** (see
*Preposizioni*). To choose the right form, the rules for the articles apply: **lo**
before s + consonant, z, gn, ps…; **l'** before a vowel.
{: .en }

| di + articolo | Partitivo | Esempi |
|---|---|---|
| di + il | **del** | del pane, del vino |
| di + lo | **dello** | dello zucchero, dello yogurt |
| di + l' | **dell'** | dell'olio (m), dell'acqua (f) |
| di + la | **della** | della farina, della frutta |
| di + i | **dei** | dei biscotti, dei libri |
| di + gli | **degli** | degli spaghetti, degli amici |
| di + le | **delle** | delle mele, delle amiche |

## Quando si usa

### Al singolare: un po' di qualcosa

Con i nomi che non si contano (cibi, bevande, materiali…) il partitivo singolare
indica *una parte, un po'*.

With nouns you can't count (food, drinks, materials…) the singular partitive means
*a part, a bit*.
{: .en }

- Vorrei **del** pane, per favore. *I'd like some bread, please.*{ .en }
- Metti **dello** zucchero nel caffè? *Do you put sugar in your coffee?*{ .en }
- Mi dai **dell'**acqua? *Can you give me some water?*{ .en }
- Ho comprato **della** frutta al mercato. *I bought some fruit at the market.*{ .en }

### Al plurale: il plurale di un / uno / una

Al plurale il partitivo indica *alcuni, un certo numero di*.

In the plural the partitive means *some, a certain number of*.
{: .en }

- un amico → **degli** amici: Stasera vengono **degli** amici a cena. *a friend → some friends: Some friends are coming to dinner tonight.*{ .en }
- uno studente → **degli** studenti: In biblioteca ci sono **degli** studenti. *a student → some students: There are some students in the library.*{ .en }
- una mela → **delle** mele: Ho comprato **delle** mele. *an apple → some apples: I bought some apples.*{ .en }
- un libro → **dei** libri: Ti ho portato **dei** libri. *a book → some books: I've brought you some books.*{ .en }

## Le alternative

Al posto del partitivo si possono usare anche altre forme, molto comuni nel parlato.

Instead of the partitive, other forms can be used too; they are very common in
speech.
{: .en }

| Partitivo | Alternativa | Si usa con… |
|---|---|---|
| del pane | **un po' di** pane | singolare (cose che non si contano) |
| dei libri | **alcuni** libri | plurale maschile |
| delle mele | **alcune** mele | plurale femminile |
| degli amici | **qualche** amico | **singolare** (ma significato plurale) |

- Vuoi **un po' di** latte? *Would you like a bit of milk?*{ .en }
- Ho invitato **alcuni** colleghi. *I invited a few colleagues.*{ .en }
- Ho letto **alcune** pagine. *I read a few pages.*{ .en }
- **Qualche** studente è arrivato in ritardo. *Some students arrived late.*{ .en }
- Sono stato a Napoli **qualche** giorno fa. *I was in Naples a few days ago.*{ .en }

!!! warning "Attenzione"
    **Qualche** è invariabile e vuole sempre il nome e il verbo al **singolare**,
    anche se il significato è plurale: *qualche amico **è** venuto*, non ~~qualche
    amici sono venuti~~. E si scrive **un po'** con l'apostrofo, non ~~un pò~~.

    **Qualche** is invariable and always takes the noun and the verb in the
    **singular**, even though the meaning is plural: **qualche amico è venuto** (some
    friends came), not **qualche amici sono venuti**. And **un po'** is written with
    an apostrophe, not **un pò**.
    {: .en }

## Quando non si usa

### Nelle frasi negative

Nelle frasi negative il partitivo di solito **si omette**. Si può anche usare *ne*
(vedi [Ci e ne](ci-e-ne.md)) o *nessun / nessuna* + singolare.

In negative sentences the partitive is usually **left out**. You can also use **ne**
(see *Ci e ne*) or **nessun / nessuna** + singular.
{: .en }

- Hai del latte? — No, non ho latte. / No, non **ne** ho. *Do you have any milk? — No, I don't have any milk. / No, I don't have any.*{ .en }
- Non ho comprato mele. *I didn't buy any apples.*{ .en }
- Qui non ho amici. = Qui non ho **nessun** amico. *I don't have any friends here.*{ .en }

### Negli elenchi

Quando si elencano più cose, il partitivo di solito non si usa.

When listing several things, the partitive is usually not used.
{: .en }

- Per la torta servono farina, uova, zucchero e burro. *For the cake you need flour, eggs, sugar and butter.*{ .en }
- Al mercato ho comprato pomodori, zucchine e patate. *At the market I bought tomatoes, courgettes and potatoes.*{ .en }

### Dopo un'altra preposizione

Dopo *di* il partitivo non si usa mai (~~di del pane~~), e dopo *con, senza* di solito
si omette.

After **di** the partitive is never used (**di del pane**), and after **con, senza**
it is usually left out.
{: .en }

- Ho bisogno di farina e uova. *I need flour and eggs.*{ .en }
- Un caffè senza zucchero, per favore. *A coffee without sugar, please.*{ .en }

!!! tip "Trucco"
    Non sei sicuro della forma del partitivo? **Un po' di** (con il singolare) e
    **alcuni / alcune** (con il plurale) sono sempre corretti.

    Not sure about the form of the partitive? **Un po' di** (with the singular) and
    **alcuni / alcune** (with the plural) are always correct.
    {: .en }

## Esercizi

Completa con l'articolo partitivo giusto (*del, dello, dell', della, dei, degli,
delle*). Se il partitivo non ci vuole (frase negativa, elenco), scrivi **—**.

Fill in with the right partitive article (**del, dello, dell', della, dei, degli,
delle**). If no partitive is needed (negative sentence, list), write **—**.
{: .en }

1. Vorrei ______ pane, per favore.
2. Metti ______ zucchero nel tè?
3. Mi porti ______ acqua?
4. Ho comprato ______ mele al mercato.
5. Stasera vengono ______ colleghi a cena.
6. Abbiamo mangiato ______ spaghetti buonissimi.
7. Nel frigo c'è ______ birra.
8. Non ho ______ soldi.
9. In questa insalata c'è ______ olio d'oliva.
10. Per la pizza servono farina, ______ acqua, lievito e sale.

??? success "Soluzioni"
    1. Vorrei **del** pane, per favore.
    2. Metti **dello** zucchero nel tè?
    3. Mi porti **dell'**acqua?
    4. Ho comprato **delle** mele al mercato.
    5. Stasera vengono **dei** colleghi a cena.
    6. Abbiamo mangiato **degli** spaghetti buonissimi.
    7. Nel frigo c'è **della** birra.
    8. **—** Non ho soldi. (frase negativa)
    9. In questa insalata c'è **dell'**olio d'oliva.
    10. **—** Per la pizza servono farina, acqua, lievito e sale. (elenco)
