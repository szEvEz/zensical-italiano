# Tabelle dei verbi

Qui trovi i verbi più importanti con i tempi principali: **presente, passato prossimo, imperfetto, futuro, condizionale, congiuntivo** e **imperativo**. I quattro verbi regolari sono i modelli per tutti gli altri verbi in **-are**, **-ere** e **-ire**.

Here you'll find the most important verbs in the main tenses: **present, present perfect, imperfect, future, conditional, subjunctive** and **imperative**. The four regular verbs are the models for all other **-are**, **-ere** and **-ire** verbs.

!!! tip "Trucchi per ricordare"
    - **Futuro** e **condizionale** hanno sempre la stessa radice: *farò → farei*, *verrò → verrei*, *andrò → andrei*. *The **future** and **conditional** always share the same stem: **farò → farei**, **verrò → verrei**, **andrò → andrei**.*{ .en }
    - Il **congiuntivo imperfetto** si forma dalla radice dell'**imperfetto**: *facevo → facessi*, *dicevo → dicessi*, *bevevo → bevessi*. *The **imperfect subjunctive** is built on the **imperfetto** stem: **facevo → facessi**, **dicevo → dicessi**, **bevevo → bevessi**.*{ .en }
    - Il **congiuntivo presente** irregolare viene spesso dalla forma **io** del presente: *faccio → faccia*, *vengo → venga*, *esco → esca*. *The irregular **present subjunctive** often comes from the **io** form of the present: **faccio → faccia**, **vengo → venga**, **esco → esca**.*{ .en }
    - L'imperativo con **Lei** è uguale al congiuntivo presente: *venga!*, *mi dica!* *The **Lei** imperative is the same as the present subjunctive: **venga!**, **mi dica!**.*{ .en }
