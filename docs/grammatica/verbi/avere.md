# Avere

**avere** — *to have*

Ausiliare: **avere** · Participio passato: **avuto** · Gerundio: **avendo**

L'**h** di *ho, hai, ha, hanno* non si pronuncia. Molte espressioni usano *avere* dove l'inglese usa *to be*: **avere fame, sete, freddo, caldo, sonno, paura, ragione, … anni**. Vedi anche la pagina [Verbo avere](../avere.md).

The **h** in **ho, hai, ha, hanno** is silent. Many expressions use **avere** where English uses **to be**: **avere fame, sete, freddo, caldo, sonno, paura, ragione, … anni** (to be hungry, thirsty, cold, hot, sleepy, afraid, right, … years old). See also the page **Verbo avere**.
{: .en }

## Indicativo

| | presente | passato prossimo | imperfetto | futuro |
|---|---|---|---|---|
| **io** | ho | ho avuto | avevo | avrò |
| **tu** | hai | hai avuto | avevi | avrai |
| **lui/lei** | ha | ha avuto | aveva | avrà |
| **noi** | abbiamo | abbiamo avuto | avevamo | avremo |
| **voi** | avete | avete avuto | avevate | avrete |
| **loro** | hanno | hanno avuto | avevano | avranno |

## Condizionale, congiuntivo e imperativo

| | condizionale | congiuntivo presente (che…) | congiuntivo imperfetto (che…) | imperativo |
|---|---|---|---|---|
| **io** | avrei | abbia | avessi | — |
| **tu** | avresti | abbia | avessi | abbi |
| **lui/lei** | avrebbe | abbia | avesse | abbia (Lei) |
| **noi** | avremmo | abbiamo | avessimo | abbiamo |
| **voi** | avreste | abbiate | aveste | abbiate |
| **loro** | avrebbero | abbiano | avessero | — |

## Esempi

- Ho trent'anni e ho due fratelli. *I'm thirty and I have two brothers.*{ .en }
- Abbiamo avuto un problema con la macchina. *We had a problem with the car.*{ .en }
- Avevo fame, quindi ho mangiato un panino. *I was hungry, so I ate a sandwich.*{ .en }
- Abbi pazienza! *Be patient!*{ .en }
