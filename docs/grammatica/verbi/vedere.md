# Vedere

**vedere** — *to see*

Ausiliare: **avere** · Participio passato: **visto** · Gerundio: **vedendo**

Il presente è regolare; irregolari sono il participio **visto** (anche *veduto*, raro) e il futuro **vedrò**. **Ci vediamo!** = See you!

The present is regular; the participle **visto** (also **veduto**, rare) and the future **vedrò** are irregular. **Ci vediamo!** = See you!
{: .en }

## Indicativo

| | presente | passato prossimo | imperfetto | futuro |
|---|---|---|---|---|
| **io** | vedo | ho visto | vedevo | vedrò |
| **tu** | vedi | hai visto | vedevi | vedrai |
| **lui/lei** | vede | ha visto | vedeva | vedrà |
| **noi** | vediamo | abbiamo visto | vedevamo | vedremo |
| **voi** | vedete | avete visto | vedevate | vedrete |
| **loro** | vedono | hanno visto | vedevano | vedranno |

## Condizionale, congiuntivo e imperativo

| | condizionale | congiuntivo presente (che…) | congiuntivo imperfetto (che…) | imperativo |
|---|---|---|---|---|
| **io** | vedrei | veda | vedessi | — |
| **tu** | vedresti | veda | vedessi | vedi |
| **lui/lei** | vedrebbe | veda | vedesse | veda (Lei) |

| **voi** | vedreste | vediate | vedeste | vedete |
| **loro** | vedrebbero | vedano | vedessero | — |

## Esempi

- Non vedo bene senza occhiali. *I can't see well without glasses.*{ .en }
- Hai visto l'ultimo film di Sorrentino? *Have you seen Sorrentino's latest film?*{ .en }
- Vedremo! *We'll see!*{ .en }
- Ci vediamo domani! *See you tomorrow!*{ .en }
