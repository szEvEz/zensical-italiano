# Uscire

**uscire** — *to go out, to leave*

Ausiliare: **essere** · Participio passato: **uscito** · Gerundio: **uscendo**

La radice cambia: **esc-** quando l'accento cade sulla radice (*esco, esci, esce, escono*), **usc-** nelle altre forme (*usciamo, uscite, uscivo*). Come *uscire*: *riuscire* (to manage, to succeed).

The stem changes: **esc-** when the stress falls on the stem (**esco, esci, esce, escono**), **usc-** in the other forms (**usciamo, uscite, uscivo**). **Riuscire** (to manage, to succeed) works the same way.
{: .en }

## Indicativo

|---|---|---|---|---|
| **io** | esco | sono uscito/a | uscivo | uscirò |

| **lui/lei** | esce | è uscito/a | usciva | uscirà |
| **noi** | usciamo | siamo usciti/e | uscivamo | usciremo |
| **voi** | uscite | siete usciti/e | uscivate | uscirete |
| **loro** | escono | sono usciti/e | uscivano | usciranno |

## Esempi

- Esco con gli amici stasera. *I'm going out with friends tonight.*{ .en }
- A che ora sei uscito di casa? *What time did you leave the house?*{ .en }
- Usciamo a fare una passeggiata? *Shall we go out for a walk?*{ .en }
- Non riesco a dormire. *I can't sleep.*{ .en }
