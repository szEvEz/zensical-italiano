# Volere

**volere** — *to want*

Ausiliare: **avere** · Participio passato: **voluto** · Gerundio: **volendo**

Per chiedere qualcosa in modo gentile si usa il condizionale **vorrei** invece di *voglio*. **Volerci** = to take, to be needed (*ci vuole un'ora*). Come gli altri modali, al passato prossimo prende l'ausiliare del verbo che segue: *sono voluto partire*.

To ask for something politely use the conditional **vorrei** instead of **voglio**. **Volerci** = to take, to be needed (**ci vuole un'ora**, it takes an hour). Like the other modals, in the passato prossimo it takes the auxiliary of the following verb: **sono voluto partire** (I wanted to leave).
{: .en }

## Indicativo

| | presente | passato prossimo | imperfetto | futuro |
|---|---|---|---|---|
| **io** | voglio | ho voluto | volevo | vorrò |
| **tu** | vuoi | hai voluto | volevi | vorrai |
| **lui/lei** | vuole | ha voluto | voleva | vorrà |
| **noi** | vogliamo | abbiamo voluto | volevamo | vorremo |
| **voi** | volete | avete voluto | volevate | vorrete |
| **loro** | vogliono | hanno voluto | volevano | vorranno |

## Condizionale, congiuntivo e imperativo

| | condizionale | congiuntivo presente (che…) | congiuntivo imperfetto (che…) |
|---|---|---|---|
| **io** | vorrei | voglia | volessi |
| **tu** | vorresti | voglia | volessi |
| **lui/lei** | vorrebbe | voglia | volesse |
| **noi** | vorremmo | vogliamo | volessimo |
| **voi** | vorreste | vogliate | voleste |
| **loro** | vorrebbero | vogliano | volessero |

!!! note "Nota"
    *Volere* non ha l'imperativo.

    **Volere** has no imperative.
    {: .en }

## Esempi

- Vorrei un cappuccino, per favore. *I'd like a cappuccino, please.*{ .en }
- Non ho voluto disturbarti. *I didn't want to disturb you.*{ .en }
- Volevo chiederti una cosa. *I wanted to ask you something.*{ .en }
- Ci vogliono due ore per arrivare. *It takes two hours to get there.*{ .en }
