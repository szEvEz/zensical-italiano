# La forma di cortesia

In italiano ci sono due modi per rivolgersi a qualcuno:
*In Italian there are two ways of addressing someone:*{ .en }

- **tu** → forma informale, con amici, familiari, bambini. *informal form, with friends, family, children.*{ .en }
- **Lei** → forma di cortesia (the polite form, a formal "you"), con persone che
  non si conoscono, in contesti formali o di lavoro. *polite form, with people you don't know, in formal or work settings.*{ .en }

## Come funziona il *Lei*

La forma di cortesia usa la **terza persona singolare** (come *lui/lei*), anche
quando si parla a una donna o a un uomo. Cambiano di conseguenza sia il
**verbo** sia i **pronomi**.

The polite form uses the **third person singular** (like **lui/lei**), whether you're
speaking to a woman or to a man. As a result, both the **verb** and the **pronouns**
change.
{: .en }

| Informale (tu) | Formale (Lei) |
|---|---|
| Tu **hai** | Lei **ha** |
| Tu **sei** | Lei **è** |
| Tu **puoi** | Lei **può** |
| Tu **vuoi** | Lei **vuole** |
| Come **ti** chiami *What's your name?*{ .en } | Come **si** chiama *What's your name?*{ .en } |
| **Ti** aiuto *I'll help you*{ .en } | **Le** aiuto → *La aiuto* / **Le** do una mano *I'll help you / I'll give you a hand*{ .en } |
| Con **te** *with you*{ .en } | Con **Lei** *with you*{ .en } |

!!! note "Nota"
    Il pronome oggetto indiretto **ti** diventa **Le** (*Le mando il
    documento*), mentre il pronome oggetto diretto **ti** diventa **La** (*La
    accompagno*). I verbi riflessivi passano a **si** (*ti senti → si sente*).

    The indirect object pronoun **ti** becomes **Le** (**Le mando il documento**,
    "I'll send you the document"), while the direct object pronoun **ti** becomes
    **La** (**La accompagno**, "I'll go with you"). Reflexive verbs switch to **si**
    (**ti senti → si sente**).
    {: .en }

!!! tip "Trucco"
    Spesso *Lei* si scrive con la **L maiuscola** per distinguerlo da *lei* =
    "she". Nel parlato non c'è differenza: conta solo il verbo alla terza
    persona.

    **Lei** is often written with a **capital L** to distinguish it from **lei** =
    "she". In speech there's no difference: only the verb in the third person
    tells you.
    {: .en }

## Esercizi

Trasforma le frasi **dal tu al Lei** (forma di cortesia).
*Change the sentences **from tu to Lei** (the polite form).*{ .en }

1. Tu hai fame? *Are you hungry?*{ .en }
2. Vuoi sederti? *Would you like to sit down?*{ .en }
3. Puoi parlare più lentamente? *Can you speak more slowly?*{ .en }
4. Come ti senti oggi? *How are you feeling today?*{ .en }
5. Hai bisogno di aiuto? *Do you need help?*{ .en }
6. Dove abiti? *Where do you live?*{ .en }
7. Quando parti? *When are you leaving?*{ .en }
8. Tu conosci Maria? *Do you know Maria?*{ .en }
9. Mi puoi spiegare questo esercizio? *Can you explain this exercise to me?*{ .en }
10. Hai visto il direttore? *Have you seen the director?*{ .en }
11. Tu lavori qui? *Do you work here?*{ .en }
12. Vuoi aspettare un momento? *Would you like to wait a moment?*{ .en }
13. Puoi chiudere la porta? *Can you close the door?*{ .en }
14. Come ti chiami? *What's your name?*{ .en }
15. Hai già mangiato? *Have you eaten already?*{ .en }
16. Tu sai usare questo programma? *Do you know how to use this program?*{ .en }
17. Mi mandi il documento? *Will you send me the document?*{ .en }
18. Vuoi venire con noi? *Do you want to come with us?*{ .en }
19. Hai capito la domanda? *Did you understand the question?*{ .en }
20. Tu puoi ripetere l'indirizzo? *Can you repeat the address?*{ .en }
21. Dove hai comprato questo libro? *Where did you buy this book?*{ .en }
22. Hai tempo domani? *Do you have time tomorrow?*{ .en }
23. Mi accompagni alla stazione? *Will you take me to the station?*{ .en }
24. Tu preferisci il tè o il caffè? *Do you prefer tea or coffee?*{ .en }
25. Hai parlato con il professore? *Have you spoken to the teacher?*{ .en }
26. Puoi firmare qui? *Can you sign here?*{ .en }
27. Tu giochi a tennis? *Do you play tennis?*{ .en }
28. Mi presti la penna? *Will you lend me your pen?*{ .en }
29. Vuoi aprire la finestra? *Would you like to open the window?*{ .en }
