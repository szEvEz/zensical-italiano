# Verbo *essere* (presente)

Il verbo **essere** (*to be*) è uno dei verbi più importanti dell'italiano.
È irregolare, quindi va imparato a memoria.

The verb **essere** (*to be*) is one of the most important verbs in Italian.
It's irregular, so it has to be learned by heart.
{: .en }

## Coniugazione al presente

| Persona | *essere* |
|---|---|
| io | **sono** |
| tu | **sei** |
| lui/lei | **è** |
| noi | **siamo** |
| voi | **siete** |
| loro | **sono** |

!!! warning "Attenzione"
    La terza persona singolare si scrive **è** con l'accento (*is*), non *e*
    (che significa *and*). Nota anche che **io sono** e **loro sono** hanno la
    stessa forma.

    The third person singular is written **è** with an accent (*is*), not **e**
    (which means *and*). Note also that **io sono** and **loro sono** have the
    same form.
    {: .en }

## Quando si usa

- **Identità** → Io **sono** Marco. *Identity → I'm Marco.*{ .en }
- **Nazionalità** → Tu **sei** tedesco. (You are German.) *Nationality → You are German.*{ .en }
- **Professione** → Lei **è** medico. *Profession → She's a doctor.*{ .en }
- **Stato / condizione** → Noi **siamo** stanchi. (We are tired.) *State / condition → We are tired.*{ .en }
- **Luogo** (dove ci si trova) → Voi **siete** a Roma. *Place (where you are) → You're in Rome.*{ .en }

## Esempi

- Io **sono** italiano e **sono** di Napoli. *I'm Italian and I'm from Naples.*{ .en }
- Tu **sei** molto gentile. *You're very kind.*{ .en }
- Maria **è** una brava insegnante. *Maria is a good teacher.*{ .en }
- Oggi noi **siamo** felici. *Today we are happy.*{ .en }
- Dove **siete**? — **Siamo** in ufficio. *Where are you? — We're at the office.*{ .en }
- I miei amici **sono** simpatici. *My friends are nice.*{ .en }
