# Condizionale presente

Il **condizionale presente** si usa per esprimere desideri, richieste gentili,
consigli e situazioni ipotetiche. In inglese corrisponde spesso a *would* / *I'd like*.

The **present conditional** is used to express wishes, polite requests,
advice and hypothetical situations. In English it often corresponds to *would* / *I'd like*.
{: .en }

## Quando si usa

- **Desideri** → *Vorrei* un caffè. (I'd like a coffee.) *Wishes → I'd like a coffee.*{ .en }
- **Richieste cortesi** → *Potresti* aiutarmi, per favore? *Polite requests → Could you help me, please?*{ .en }
- **Consigli** → *Dovresti* riposare di più. *Advice → You should rest more.*{ .en }
- **Ipotesi** (periodo ipotetico) → Se avessi tempo, *viaggerei* di più.
  → vedi [congiuntivo imperfetto](congiuntivo-imperfetto.md) *Hypotheses (conditional sentences) → If I had time, I would travel more. See the imperfect subjunctive.*{ .en }
- **Notizia non confermata** → Il treno *arriverebbe* alle nove. *Unconfirmed news → The train is said to arrive at nine.*{ .en }

## Come si forma

Si parte dalla **radice del futuro** e si aggiungono le desinenze:

Start from the **future stem** and add the endings:
{: .en }

| Persona | Desinenza |
|---|---|
| io | **-ei** |
| tu | **-esti** |
| lui/lei | **-ebbe** |
| noi | **-emmo** |
| voi | **-este** |
| loro | **-ebbero** |

!!! note "Attenzione ai verbi in **-are**"
    Nei verbi in **-are** la *a* diventa *e*: parl**are** → parl**er**ei
    (come nel futuro).

    In **-are** verbs the *a* becomes *e*: parl**are** → parl**er**ei
    (as in the future).
    {: .en }

## Verbi regolari

| | parl**are** | prend**ere** | dorm**ire** |
|---|---|---|---|
| io | parlerei | prenderei | dormirei |
| tu | parleresti | prenderesti | dormiresti |
| lui/lei | parlerebbe | prenderebbe | dormirebbe |
| noi | parleremmo | prenderemmo | dormiremmo |
| voi | parlereste | prendereste | dormireste |
| loro | parlerebbero | prenderebbero | dormirebbero |

## Verbi irregolari più comuni

La radice è la stessa del **futuro semplice**. Ecco la forma **io** (le desinenze
sono sempre -ei, -esti, -ebbe, -emmo, -este, -ebbero):

The stem is the same as in the **simple future**. Here is the **io** form (the endings
are always -ei, -esti, -ebbe, -emmo, -este, -ebbero):
{: .en }

| Verbo | io (condizionale) |
|---|---|
| essere | **sarei** |
| avere | **avrei** |
| fare | **farei** |
| dare | **darei** |
| stare | **starei** |
| andare | **andrei** |
| dovere | **dovrei** |
| potere | **potrei** |
| sapere | **saprei** |
| vedere | **vedrei** |
| vivere | **vivrei** |
| volere | **vorrei** |
| venire | **verrei** |
| rimanere | **rimarrei** |
| bere | **berrei** |

## Esempi

- **Vorrei** affittare un appartamento a Milano dal 15 al 25 agosto. *I'd like to rent a flat in Milan from 15 to 25 August.*{ .en }
- **Vorrei** comprare un biglietto per il Vietnam. *I'd like to buy a ticket to Vietnam.*{ .en }
- **Vorrei** prenotare un tavolo per due persone alle 20. *I'd like to book a table for two at 8 p.m.*{ .en }
- Mi **interesserebbe** saperne un po' di più. *I'd be interested in knowing a bit more about it.*{ .en }
- Che cosa ti **piacerebbe** sapere? *What would you like to know?*{ .en }
- Io **dovrei** trovare una soluzione, ma non l'ho ancora trovata. *I should find a solution, but I haven't found one yet.*{ .en }

## Esercizi

Coniuga il verbo tra parentesi al condizionale presente.

Conjugate the verb in brackets in the present conditional.
{: .en }

1. (io – volere) __________ un gelato. *I'd like an ice cream.*{ .en }
2. (tu – potere) __________ chiudere la finestra? *Could you close the window?*{ .en }
3. (lui – dovere) __________ studiare di più. *He should study more.*{ .en }
4. (noi – andare) __________ volentieri al mare. *We'd love to go to the seaside.*{ .en }
5. (voi – essere) __________ così gentili da aspettare? *Would you be so kind as to wait?*{ .en }
6. (loro – mangiare) __________ volentieri una pizza. *They'd happily eat a pizza.*{ .en }
7. (io – avere) __________ bisogno di aiuto. *I would need some help.*{ .en }
8. (tu – venire) __________ con me domani? *Would you come with me tomorrow?*{ .en }
