# Pronomi relativi

I **pronomi relativi** collegano due frasi e si riferiscono a un nome già nominato
(l'antecedente), evitando di ripeterlo. I due più importanti sono **che** e **cui**.

**Relative pronouns** link two clauses and refer to a noun already mentioned
(the antecedent), so you don't have to repeat it. The two most important ones are
**che** and **cui**.
{: .en }

## *che* — soggetto e oggetto

**Che** è invariabile e si usa quando il pronome è **soggetto** o **complemento
oggetto** della frase relativa (senza preposizione).

**Che** is invariable and is used when the pronoun is the **subject** or the
**direct object** of the relative clause (with no preposition).
{: .en }

- La ragazza **che** parla è Maria. (che = soggetto: la ragazza parla) *The girl who is speaking is Maria. (che = subject: the girl is speaking)*{ .en }
- Il libro **che** leggo è interessante. (che = oggetto: leggo il libro) *The book (that) I'm reading is interesting. (che = object: I'm reading the book)*{ .en }

!!! note "Nota"
    **Che** non cambia mai: vale per maschile, femminile, singolare e plurale.
    In inglese corrisponde a *who / which / that*.

    **Che** never changes: it works for masculine, feminine, singular and plural.
    In English it corresponds to "who / which / that".
    {: .en }

## *cui* — dopo una preposizione

**Cui** si usa quando il pronome relativo è retto da una **preposizione**
(*a, di, con, per, in, da*…). La preposizione va **prima** di *cui*.

**Cui** is used when the relative pronoun is governed by a **preposition**
(**a, di, con, per, in, da**…). The preposition goes **before** **cui**.
{: .en }

| Preposizione + cui | Significato |
|---|---|
| **a cui** | a chi / al quale *to whom / to which*{ .en } |
| **di cui** | di chi / del quale *of / about whom, of / about which*{ .en } |
| **con cui** | con chi / con il quale *with whom / with which*{ .en } |
| **per cui** | per chi / motivo per il quale *for whom / the reason why*{ .en } |
| **in cui** | nel quale / momento o luogo *in which (time or place: when, where)*{ .en } |
| **da cui** | dal quale / da dove *from whom / from which, from where*{ .en } |

### Esempi

- Antonio è quell'amico **a cui** ho regalato una bicicletta. *Antonio is the friend I gave a bicycle to.*{ .en }
- Antonio è quell'amico **di cui** ti ho parlato la settimana scorsa. *Antonio is the friend I told you about last week.*{ .en }
- Sono andato con un amico **con cui** andrò sulle Dolomiti a giugno. *I went with a friend I'm going to the Dolomites with in June.*{ .en }

## *che* o *cui*?

!!! tip "Trucco"
    - Nessuna preposizione → **che** *No preposition: use **che**.*{ .en }
    - C'è una preposizione (a, di, con, per, in, da) → **cui** *There's a preposition (a, di, con, per, in, da): use **cui**.*{ .en }

    Prova a rifare la frase: se dici *parlo **di** quell'amico*, allora nel relativo
    userai *di cui*. Se dici *quell'amico legge*, userai *che*.

    Try rephrasing the sentence: if you say **parlo di quell'amico** ("I'm talking about
    that friend"), then in the relative clause you'll use **di cui**. If you say
    **quell'amico legge** ("that friend reads"), you'll use **che**.
    {: .en }

!!! warning "Attenzione"
    Con *cui* la preposizione **non** si articola: si dice *di cui*, *a cui*
    (mai *del cui*, *al cui*).

    With **cui** the preposition does **not** combine with an article: you say
    **di cui**, **a cui** (never **del cui**, **al cui**).
    {: .en }

## Esercizi

Completa con **che** oppure con la giusta forma **preposizione + cui**.
*Fill in with **che** or with the correct **preposition + cui** form.*{ .en }

1. Questa è la casa ______ sono nato. (in) *This is the house … I was born.*{ .en }
2. Il film ______ abbiamo visto ieri era bellissimo. *The film … we saw yesterday was wonderful.*{ .en }
3. Ecco l'amico ______ ti ho parlato. (di) *Here's the friend … I told you about.*{ .en }
4. La persona ______ telefono è mia zia. (a) *The person … I'm phoning is my aunt.*{ .en }
5. Il motivo ______ sono in ritardo è il traffico. (per) *The reason … I'm late is the traffic.*{ .en }
6. La penna ______ è sul tavolo è mia. *The pen … is on the table is mine.*{ .en }
7. La città ______ vengo è piccola. (da) *The town … I come from is small.*{ .en }
8. Ho un collega ______ lavoro da dieci anni. (con) *I have a colleague … I've been working with for ten years.*{ .en }

??? success "Soluzioni"
    1. in cui
    2. che
    3. di cui
    4. a cui
    5. per cui
    6. che
    7. da cui
    8. con cui
