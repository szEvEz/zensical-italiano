# Passato prossimo

Il **passato prossimo** è il tempo più usato per raccontare azioni concluse
nel passato (*simple past / present perfect*). Corrisponde spesso all'inglese *I ate* / *I have eaten*,
*I went* / *I have gone*.

The **passato prossimo** is the tense most used to talk about completed actions
in the past. It often corresponds to the English simple past or present perfect: *I ate* / *I have eaten*,
*I went* / *I have gone*.
{: .en }

## Come si forma

**Presente di _avere_ o _essere_** + **participio passato**.

**Present tense of avere or essere** + **past participle**.
{: .en }

Esempi: io **ho** mangi**ato**, io **sono** and**ato**.

Examples: io **ho** mangi**ato** (I ate / I have eaten), io **sono** and**ato** (I went / I have gone).
{: .en }

## Il participio passato regolare

| Infinito | Terminazione | Participio |
|---|---|---|
| -are | **-ato** | mangi**are** → mangi**ato** |
| -ere | **-uto** | cad**ere** → cad**uto** |
| -ire | **-ito** | cap**ire** → cap**ito** |

## *Essere* o *avere*?

La maggior parte dei verbi usa **avere**. Si usa **essere** con:

Most verbs take **avere**. **Essere** is used with:
{: .en }

- **verbi di movimento e stato**: andare, venire, entrare, uscire, salire,
  scendere, partire, arrivare, stare, rimanere, restare; *verbs of movement and state*{ .en }
- **verbi di cambiamento**: nascere, morire, diventare; *verbs of change*{ .en }
- **verbi riflessivi/pronominali**: svegliarsi, alzarsi, lavarsi… *reflexive/pronominal verbs*{ .en }

!!! warning "L'accordo con *essere*"
    Con **essere** il participio si accorda in **genere e numero** con il soggetto:

    With **essere**, the participle agrees in **gender and number** with the subject:
    {: .en }

    - Marco è and**ato** / Maria è and**ata** *Marco went / Maria went*{ .en }
    - I ragazzi sono and**ati** / Le ragazze sono and**ate** *The boys went / The girls went*{ .en }

    Con **avere** il participio di solito **non** cambia:
    *ho mangiato*, *abbiamo mangiato*.

    With **avere**, the participle usually does **not** change:
    *ho mangiato*, *abbiamo mangiato*.
    {: .en }

## Esempi

- Io **ho mangiato** una pizza. (I ate a pizza.)
- Ieri **ho letto** un libro interessante. *Yesterday I read an interesting book.*{ .en }
- Io **sono andato** al bar con gli amici. *I went to the bar with my friends.*{ .en }
- Maria **è partita** per Roma. *Maria has left for Rome.*{ .en }
- Stamattina mi **sono svegliato** presto. (riflessivo → essere) *This morning I woke up early. (reflexive → essere)*{ .en }
- Noi **siamo rimasti** a casa tutto il giorno. *We stayed at home all day.*{ .en }
