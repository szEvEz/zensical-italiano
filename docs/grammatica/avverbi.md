# Avverbi di modo

Gli avverbi di modo dicono **come** si fa un'azione (how?). In italiano molti si formano aggiungendo **-mente** all'aggettivo.

Adverbs of manner tell you **how** an action is done. In Italian many of them are formed by adding **-mente** to the adjective.
{: .en }

## Formazione

### Regola base: aggettivo femminile + -mente

Si parte dalla forma **femminile** dell'aggettivo e si aggiunge **-mente**.
*You start from the **feminine** form of the adjective and add **-mente**.*{ .en }

- lento → lent**a** → **lentamente** *slow → slowly*{ .en }
- sicuro → sicur**a** → **sicuramente** *sure → surely*{ .en }

### Aggettivi in -e

Gli aggettivi che finiscono in **-e** (uguali al maschile e femminile) aggiungono direttamente **-mente**.
*Adjectives ending in **-e** (the same in the masculine and feminine) add **-mente** directly.*{ .en }

- veloce → **velocemente** *fast → quickly*{ .en }

### Aggettivi in -le / -re

Gli aggettivi che finiscono in **-le** o **-re** (dopo una vocale) **perdono la -e finale** prima di **-mente**.
*Adjectives ending in **-le** or **-re** (after a vowel) **drop the final -e** before **-mente**.*{ .en }

- facile → facil~~e~~ → **facilmente** *easy → easily*{ .en }
- gentile → gentil~~e~~ → **gentilmente** *kind → kindly*{ .en }
- regolare → regolar~~e~~ → **regolarmente** *regular → regularly*{ .en }

!!! warning "Attenzione"
    Solo -le / -re preceduti da vocale perdono la -e: *facile → facilmente*, ma *folle → follemente* (dopo consonante si mantiene).
    *Only -le / -re preceded by a vowel drop the -e: **facile → facilmente**, but **folle → follemente** (after a consonant it stays).*{ .en }

## Avverbi irregolari

Due avverbi molto comuni **non** si formano con -mente:
*Two very common adverbs are **not** formed with -mente:*{ .en }

| Aggettivo | Avverbio |
|-----------|----------|
| buono *good*{ .en }     | **bene** (well) |
| cattivo *bad*{ .en }   | **male** (badly) |

## Aggettivo o avverbio?

L'**aggettivo** descrive un nome. L'**avverbio** descrive un verbo.
*The **adjective** describes a noun. The **adverb** describes a verb.*{ .en }

- Anna è una **brava** cantante. *(aggettivo → descrive "cantante")* *Anna is a good singer. (adjective → describes "cantante")*{ .en }
- Anna canta **bene**. *(avverbio → descrive "canta")* *Anna sings well. (adverb → describes "canta")*{ .en }

!!! tip "Trucco"
    Se puoi chiedere *"com'è?"* → aggettivo. Se puoi chiedere *"come fa?"* → avverbio.
    *If you can ask **"com'è?"** ("what is it like?") → adjective. If you can ask **"come fa?"** ("how does it do it?") → adverb.*{ .en }
