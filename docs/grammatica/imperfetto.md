# Imperfetto

L'**imperfetto** (*imperfect — the descriptive past: "used to …", "was …ing"*) descrive
azioni abituali, situazioni e sfondi nel passato. Si contrappone al
[passato prossimo](passato-prossimo.md), che indica azioni puntuali e concluse.

The **imperfetto** describes habitual actions, situations and background in the past
(in English often *used to …* or *was …ing*). It contrasts with the
[passato prossimo](passato-prossimo.md), which expresses one-off, completed actions.
{: .en }

## Come si forma

Si toglie la terminazione dell'infinito e si aggiungono le desinenze:

Remove the infinitive ending and add these endings:
{: .en }

| | parl**are** | prend**ere** | dorm**ire** |
|---|---|---|---|
| io | parl**avo** | prend**evo** | dorm**ivo** |
| tu | parl**avi** | prend**evi** | dorm**ivi** |
| lui/lei | parl**ava** | prend**eva** | dorm**iva** |
| noi | parl**avamo** | prend**evamo** | dorm**ivamo** |
| voi | parl**avate** | prend**evate** | dorm**ivate** |
| loro | parl**avano** | prend**evano** | dorm**ivano** |

!!! tip "Trucco"
    L'imperfetto è molto **regolare**: solo la vocale cambia (-av-, -ev-, -iv-).
    L'accento cade sempre sulla stessa sillaba.

    The imperfetto is very **regular**: only the vowel changes (-av-, -ev-, -iv-).
    The stress always falls on the same syllable.
    {: .en }

## Irregolari comuni

| | essere | fare | dire | bere |
|---|---|---|---|---|
| io | **ero** | facevo | dicevo | bevevo |
| tu | **eri** | facevi | dicevi | bevevi |
| lui/lei | **era** | faceva | diceva | beveva |
| noi | **eravamo** | facevamo | dicevamo | bevevamo |
| voi | **eravate** | facevate | dicevate | bevevate |
| loro | **erano** | facevano | dicevano | bevevano |

!!! note "Nota"
    *Fare*, *dire* e *bere* usano una radice più lunga (fac-, dic-, bev-) che
    viene dal latino. Solo *essere* è davvero irregolare.

    **Fare**, **dire** and **bere** use a longer stem (fac-, dic-, bev-) that
    comes from Latin. Only **essere** is truly irregular.
    {: .en }

## Imperfetto o passato prossimo?

| Imperfetto | Passato prossimo |
|---|---|
| azione **abituale** (*ogni giorno andavo…*) *habitual action (every day I used to go…)*{ .en } | azione **puntuale** (*ieri sono andato…*) *one-off action (yesterday I went…)*{ .en } |
| **descrizione** / sfondo (*faceva freddo*) *description / background (it was cold)*{ .en } | azione **conclusa** (*ho chiuso la porta*) *completed action (I closed the door)*{ .en } |
| azione **in corso** interrotta da un'altra *an ongoing action interrupted by another*{ .en } | azione **che interrompe** *the action that interrupts*{ .en } |

Esempio classico:
Mentre **studiavo** (imperfetto = sfondo), **è squillato** (passato prossimo = puntuale) il telefono.

A classic example:
While **I was studying** (imperfetto = background), the phone **rang** (passato prossimo = one-off action).
{: .en }

## Esercizi

Scegli l'**imperfetto** o il **passato prossimo** e coniuga il verbo tra parentesi.

Choose the **imperfetto** or the **passato prossimo** and conjugate the verb in brackets.
{: .en }

1. Ieri io ___ una torta. (fare) *Yesterday I ___ a cake. (make)*{ .en }
2. Quando ero bambino, ___ sempre al mare. (andare) *When I was a child, I always ___ to the seaside. (go)*{ .en }
3. Mentre Maria ___, il telefono è squillato. (studiare) *While Maria ___, the phone rang. (study)*{ .en }
4. Stamattina noi ___ molto presto. (svegliarsi) *This morning we ___ very early. (wake up)*{ .en }
5. Da piccoli Luca e Paolo ___ spesso insieme. (giocare) *As children, Luca and Paolo often ___ together. (play)*{ .en }
6. Ieri sera tu ___ un film interessante. (vedere) *Last night you ___ an interesting film. (see)*{ .en }
7. Quando pioveva, noi ___ a casa. (restare) *When it rained, we ___ at home. (stay)*{ .en }
8. L'anno scorso loro ___ in Spagna. (andare) *Last year they ___ to Spain. (go)*{ .en }
9. Mia nonna ___ sempre il tè alle cinque. (bere) *My grandmother always ___ tea at five. (drink)*{ .en }
10. Io ___ la porta perché avevo freddo. (chiudere) *I ___ the door because I was cold. (close)*{ .en }
