# Pronomi diretti

I **pronomi diretti** sostituiscono il **complemento oggetto**, cioè la cosa o la
persona su cui ricade direttamente l'azione del verbo (la domanda è *chi?* / *che
cosa?*). Servono a non ripetere sempre lo stesso nome.

**Direct object pronouns** replace the **direct object**, that is, the thing or person
directly affected by the action of the verb (the question is **chi?** / **che cosa?**,
"who?" / "what?"). They save you from repeating the same noun over and over.
{: .en }

## Le forme

| Persona | Pronome diretto |
|---|---|
| io | **mi** |
| tu | **ti** |
| lui / esso (maschile) | **lo** |
| lei / essa (femminile) | **la** |
| noi | **ci** |
| voi | **vi** |
| loro (maschile) | **li** |
| loro (femminile) | **le** |

!!! note "Nota"
    Il pronome va **prima del verbo** coniugato: Io **la** mangio.
    Davanti a vocale o *h*, **lo** e **la** possono diventare **l'**:
    L'ho vista ieri. (= La ho vista.)

    The pronoun goes **before the conjugated verb**: **Io la mangio** (I eat it).
    Before a vowel or **h**, **lo** and **la** can become **l'**:
    **L'ho vista ieri** (I saw her yesterday). (= **La ho vista**.)
    {: .en }

## Come funziona

Il pronome diretto prende il posto dell'oggetto e concorda con esso in **genere**
(maschile/femminile) e **numero** (singolare/plurale).

The direct object pronoun takes the place of the object and agrees with it in **gender**
(masculine/feminine) and **number** (singular/plural).
{: .en }

- Io mangio **la mela** → Io **la** mangio. *I eat the apple → I eat it.*{ .en }
- Io mangio **il pollo** → Io **lo** mangio. *I eat the chicken → I eat it.*{ .en }
- Io mangio **le mele** → Io **le** mangio. *I eat the apples → I eat them.*{ .en }
- Io mangio **i pomodori** → Io **li** mangio. *I eat the tomatoes → I eat them.*{ .en }

## La particella *ne*

**Ne** è una particella pronominale che sostituisce una cosa introdotta da una
**quantità** o da *di* (ne = *di quella cosa*, in inglese spesso *of it / of them*).

**Ne** is a pronominal particle that replaces something introduced by a **quantity**
or by **di** (ne = **di quella cosa**, "of that thing"; in English often "of it / of them",
or simply left out).
{: .en }

- «Quante mele mangi?» → «**Ne** mangio due.» (ne = di quelle mele) *"How many apples do you eat?" → "I eat two (of them)." (ne = of those apples)*{ .en }
- «Quanti fiori hai comprato?» → «**Ne** ho comprati venti.» *"How many flowers did you buy?" → "I bought twenty (of them)."*{ .en }

!!! warning "Attenzione: accordo del participio"
    Con i tempi composti (per esempio il passato prossimo), il **participio**
    concorda con il pronome diretto o con *ne*:

    With compound tenses (for example the **passato prossimo**), the **past participle**
    agrees with the direct object pronoun or with **ne**:
    {: .en }

    - Le mele? Le ho mangiat**e**. *The apples? I ate them.*{ .en }
    - I pomodori? Li ho mangiat**i**. *The tomatoes? I ate them.*{ .en }
    - Fiori? Ne ho comprat**i** venti. *Flowers? I bought twenty (of them).*{ .en }

!!! tip "Trucco"
    I pronomi diretti rispondono a *chi?/che cosa?*; i
    [pronomi indiretti](pronomi-indiretti.md) rispondono a *a chi?* (a + persona).

    Direct object pronouns answer **chi? / che cosa?** ("who?" / "what?");
    [indirect object pronouns](pronomi-indiretti.md) answer **a chi?** ("to whom?", **a** + person).
    {: .en }

## Esercizi

Riscrivi le frasi sostituendo il complemento oggetto con il pronome diretto (o con
*ne* dove indicato).

Rewrite the sentences, replacing the direct object with the direct object pronoun
(or with **ne** where indicated).
{: .en }

1. Io leggo **il giornale**. → ______________ *I read the newspaper.*{ .en }
2. Marco compra **la macchina**. → ______________ *Marco buys the car.*{ .en }
3. Noi guardiamo **i film**. → ______________ *We watch the films.*{ .en }
4. Voi conoscete **le mie amiche**? → ______________ *Do you know my (female) friends?*{ .en }
5. Ho visto **Anna** al mercato. → ______________ *I saw Anna at the market.*{ .en }
6. «Quanti libri hai letto?» → «______________ tre.» (con *ne*) *"How many books have you read?" → "… three." (with **ne**)*{ .en }
7. Prendi **il caffè**? → ______________ *Are you having the coffee?*{ .en }
8. Hanno invitato **te e Luca**. → ______________ hanno invitati. *They invited you and Luca.*{ .en }

??? success "Soluzioni"
    1. Io **lo** leggo.
    2. Marco **la** compra.
    3. Noi **li** guardiamo.
    4. **Le** conoscete?
    5. **L'**ho vista al mercato. (La ho vista)
    6. «**Ne** ho letti tre.»
    7. **Lo** prendi?
    8. **Vi** hanno invitati.
