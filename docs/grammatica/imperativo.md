# Imperativo

L'**imperativo** (the imperative) si usa per dare ordini, istruzioni, consigli e
inviti: *Vieni qui!*, *Gira a destra!*, *Prendi un caffè!*. Ha forme proprie per
**tu**, **noi** e **voi**; per la forma di cortesia **Lei** si usa il
[congiuntivo presente](congiuntivo-presente.md).

The **imperative** is used to give orders, instructions, advice and
invitations: **Vieni qui!** (Come here!), **Gira a destra!** (Turn right!),
**Prendi un caffè!** (Have a coffee!). It has its own forms for **tu**, **noi**
and **voi**; for the polite **Lei** form the **present subjunctive** is used.
{: .en }

## Come si forma

| | mangi**are** | ved**ere** | dorm**ire** | fin**ire** (-isc-) |
|---|---|---|---|---|
| (tu) | mangia! | vedi! | dormi! | finisci! |
| (Lei) | mangi! | veda! | dorma! | finisca! |
| (noi) | mangiamo! | vediamo! | dormiamo! | finiamo! |
| (voi) | mangiate! | vedete! | dormite! | finite! |

Le forme di **noi** e **voi** sono uguali al
[presente indicativo](presente-indicativo.md). Nei verbi in **-ere** e **-ire**
anche la forma di **tu** è uguale al presente (*vedi, dormi*); nei verbi in
**-are** invece finisce in **-a**: *mangia!*, *parla!*, *ascolta!*.

The **noi** and **voi** forms are the same as the **present indicative**. In
**-ere** and **-ire** verbs the **tu** form is also the same as the present
(**vedi, dormi**); in **-are** verbs, however, it ends in **-a**: **mangia!**,
**parla!**, **ascolta!**.
{: .en }

### La forma di cortesia (Lei)

Con le persone a cui diamo del **Lei** (vedi la
[forma di cortesia](forma-di-cortesia.md)) l'imperativo prende la forma del
congiuntivo presente: *Scusi!*, *Venga pure!*, *Mi dica!*, *Si accomodi!*.

With people we address as **Lei** (see **forma di cortesia**), the imperative
takes the form of the present subjunctive: **Scusi!** (Excuse me!), **Venga
pure!** (Do come in!), **Mi dica!** (Tell me / How can I help?), **Si
accomodi!** (Have a seat!).
{: .en }

## Verbi irregolari

| Infinito | tu | Lei | voi |
|---|---|---|---|
| essere | **sii** | sia | siate |
| avere | **abbi** | abbia | abbiate |
| sapere | **sappi** | sappia | sappiate |
| andare | **va'** / vai | vada | andate |
| dare | **da'** / dai | dia | date |
| fare | **fa'** / fai | faccia | fate |
| stare | **sta'** / stai | stia | state |
| dire | **di'** | dica | dite |
| venire | **vieni** | venga | venite |
| uscire | **esci** | esca | uscite |
| tenere | **tieni** | tenga | tenete |

!!! note "Nota"
    Le forme brevi **va', da', fa', sta', di'** si scrivono con l'**apostrofo**,
    non con l'accento. Per *andare, dare, fare, stare* sono corrette anche le
    forme **vai, dai, fai, stai**, molto comuni nel parlato. *Di'* invece è
    l'unica forma di *dire*.

    The short forms **va', da', fa', sta', di'** are written with an
    **apostrophe**, not an accent. For **andare, dare, fare, stare** the forms
    **vai, dai, fai, stai** are also correct and very common in speech. **Di'**,
    on the other hand, is the only form of **dire**.
    {: .en }

## L'imperativo negativo

- **tu** → **non + infinito**: Non **mangiare** troppo! Non **parlare**! *For **tu**: **non** + infinitive. Don't eat too much! Don't talk!*{ .en }
- **noi / voi** → **non** + la forma normale: Non **mangiamo** qui! Non
  **parlate**! *For **noi / voi**: **non** + the normal form. Let's not eat here! Don't talk!*{ .en }
- **Lei** → **non** + la forma normale: Non **si preoccupi**! *For **Lei**: **non** + the normal form. Don't worry!*{ .en }

!!! warning "Attenzione"
    Con **tu** non si dice ~~Non mangia!~~ o ~~Non mangi!~~, ma **Non mangiare!**
    E non ~~Non sii triste~~, ma **Non essere triste!**

    With **tu** you don't say **Non mangia!** or **Non mangi!** ✗, but **Non
    mangiare!** And not **Non sii triste** ✗, but **Non essere triste!** (Don't
    be sad!)
    {: .en }

## La posizione dei pronomi

Con **tu**, **noi** e **voi** i pronomi
([diretti](pronomi-diretti.md), [indiretti](pronomi-indiretti.md), riflessivi,
*ci* e *ne*) si attaccano **alla fine** del verbo. Con **Lei** vanno **prima**
del verbo.

With **tu**, **noi** and **voi**, pronouns (direct, indirect, reflexive, **ci**
and **ne**) are attached **to the end** of the verb. With **Lei** they go
**before** the verb.
{: .en }

- Il libro? **Prendilo**! — Lo **prenda**! (Lei) *The book? Take it!*{ .en }
- **Alzati**, è tardi! — Si **alzi**! (Lei) *Get up, it's late!*{ .en }
- **Ditemi** tutto! *Tell me everything!*{ .en }
- **Andiamoci** insieme! *Let's go there together!*{ .en }

### Le forme brevi: la doppia consonante

Quando un pronome si attacca a **va', da', fa', sta', di'**, la consonante del
pronome **raddoppia** (tranne con *gli*).

When a pronoun is attached to **va', da', fa', sta', di'**, the pronoun's
consonant is **doubled** (except with **gli**).
{: .en }

| Forma breve + pronome | Risultato | |
|---|---|---|
| da' + mi | **dammi** | Dammi la mano! *Give me your hand!*{ .en } |
| fa' + lo | **fallo** | Fallo subito! *Do it right away!*{ .en } |
| fa' + mi | **fammi** | Fammi vedere! *Let me see!*{ .en } |
| di' + mi | **dimmi** | Dimmi la verità! *Tell me the truth!*{ .en } |
| di' + me + lo | **dimmelo** | Dimmelo! *Tell me (it)!*{ .en } |
| va' + ci | **vacci** | Vacci tu! *You go (there)!*{ .en } |
| sta' + mi + bene | **stammi bene** | Stammi bene! *Take care!*{ .en } |
| da' + gli | **dagli** (senza doppia) | Dagli il libro! *Give him the book!*{ .en } |

Per le combinazioni come *me lo, glielo* vedi i
[pronomi combinati](pronomi-combinati.md).

For combinations like **me lo, glielo**, see **pronomi combinati**.
{: .en }

### Imperativo negativo con i pronomi

Con il **tu** negativo il pronome può stare **dopo** l'infinito (attaccato) o
**prima** dell'infinito. Le due forme sono corrette.

With the negative **tu** form the pronoun can go **after** the infinitive
(attached) or **before** the infinitive. Both forms are correct.
{: .en }

- Non **farlo**! = Non **lo fare**! *Don't do it!*{ .en }
- Non **preoccuparti**! = Non **ti preoccupare**! *Don't worry!*{ .en }
- Non **dirmelo**! = Non **me lo dire**! *Don't tell me!*{ .en }
- Non **dimenticarlo**! = Non **lo dimenticare**! *Don't forget it!*{ .en }

!!! tip "Trucco"
    L'imperativo può sembrare brusco. Per essere più gentile aggiungi **per
    favore** o **pure** (*Entra pure!*), oppure usa il
    [condizionale presente](condizionale-presente.md): *Potresti chiudere la
    finestra?*

    The imperative can sound abrupt. To be more polite, add **per favore** or
    **pure** (**Entra pure!**, Do come in!), or use the **condizionale
    presente**: **Potresti chiudere la finestra?** (Could you close the window?)
    {: .en }

## Quando si usa

- **Ordini e istruzioni** → **Gira** a destra e poi **prendi** la seconda strada. *Turn right and then take the second street.*{ .en }
- **Consigli** → **Bevi** tanta acqua e **riposati**! *Drink lots of water and get some rest!*{ .en }
- **Inviti** → **Venite** a cena da noi sabato! *Come to dinner at ours on Saturday!*{ .en }
- **Proposte** (noi) → **Andiamo** al cinema stasera! *Let's go to the cinema tonight!*{ .en }
- **Ricette** → **Tagliate** le cipolle e **mettetele** in padella. *Chop the onions and put them in the pan.*{ .en }
- **Forma di cortesia** → **Scusi**, mi **dica** dov'è la stazione. *Excuse me, tell me where the station is.*{ .en }
