# Verbi pronominali idiomatici

Alcuni verbi italiani si combinano con i pronomi **la** e **ci** e assumono un
significato particolare, diverso dal verbo di base. Si chiamano **verbi
pronominali**. Qui vediamo due dei più utili nella lingua parlata.

Some Italian verbs combine with the pronouns **la** and **ci** and take on a
special meaning, different from the basic verb. They are called **verbi
pronominali** (pronominal verbs). Here we look at two of the most useful ones in spoken Italian.
{: .en }

## Prendersela

**Prendersela** significa **arrabbiarsi** o offendersi (to get annoyed / to take
offence).

**Prendersela** means **to get angry** or to take offence.
{: .en }

| Persona | Forma |
|---|---|
| io | me la prendo |
| tu | te la prendi |
| lui/lei | se la prende |
| noi | ce la prendiamo |
| voi | ve la prendete |
| loro | se la prendono |

!!! note "Nota"
    *Io me la prendo* = mi arrabbio (I get upset / I'm angry). Spesso si usa
    con **per** + causa: *Non prendertela per una sciocchezza!*

    *Io me la prendo* = mi arrabbio (I get upset / I'm angry). It's often used
    with **per** + cause: *Non prendertela per una sciocchezza!* (Don't get upset over a trifle!)
    {: .en }

### Forma negativa e con i modali

Con un verbo modale (dovere, potere, volere) il pronome si attacca
all'infinito: **prender + me/te/se + la**.

With a modal verb (dovere, potere, volere) the pronoun is attached
to the infinitive: **prender + me/te/se + la**.
{: .en }

- Io non devo **prendermela**. *I mustn't get upset.*{ .en }
- Tu non devi **prendertela**. *You mustn't get upset.*{ .en }
- Lui non deve **prendersela**. *He mustn't get upset.*{ .en }

## Farcela

**Farcela** significa **riuscire** / ce la fare a fare qualcosa (to make it, to manage).

**Farcela** means **to succeed**, to manage to do something.
{: .en }

| Persona | Forma |
|---|---|
| io | ce la faccio |
| tu | ce la fai |
| lui/lei | ce la fa |
| noi | ce la facciamo |
| voi | ce la fate |
| loro | ce la fanno |

### Esempi

- «**Ce la fai** ad essere in ufficio alle 9 domani mattina?» – «Sì, **ce la
  faccio**.» *“Can you make it to the office by 9 tomorrow morning?” – “Yes, I can.”*{ .en }
- Non so se **ce la faccio** a trovare un capretto per la cena del 24. *I don't know if I'll manage to find a kid goat for dinner on the 24th.*{ .en }

!!! tip "Trucco"
    Dopo **farcela** l'azione si introduce con **a** + infinito:
    *ce la faccio **a** finire*, *ce la fai **ad** arrivare*.

    After **farcela**, the action is introduced with **a** + infinitive:
    *ce la faccio **a** finire* (I can manage to finish), *ce la fai **ad** arrivare* (you can make it).
    {: .en }

## Esercizi

Completa con la forma corretta di **prendersela** o **farcela**.

Complete with the correct form of **prendersela** or **farcela**.
{: .en }

1. (io – farcela) __________ a finire il lavoro entro stasera. *I can manage to finish the work by tonight.*{ .en }
2. Non (tu – prendersela) __________ se ti faccio una critica. *Don't get upset if I criticise you.*{ .en }
3. Loro non (farcela) __________ a venire alla festa. *They can't make it to the party.*{ .en }
4. Lui (prendersela) __________ sempre per ogni piccola cosa. *He always gets upset over every little thing.*{ .en }
5. «(voi – farcela) __________ ad arrivare in tempo?» – «Sì, __________.» *“Can you make it on time?” – “Yes, we can.”*{ .en }

??? success "Soluzioni"
    1. Ce la faccio
    2. prendertela (Non prendertela ...)
    3. ce la fanno
    4. se la prende
    5. Ce la fate – ce la facciamo
