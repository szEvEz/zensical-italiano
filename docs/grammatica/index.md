# Grammatica

Benvenuto nella sezione di **grammatica**! Qui trovi le regole principali
dell'italiano con tabelle, esempi ed esercizi con soluzioni. Ogni pagina è pensata
per un livello **A2/B1**, con brevi spiegazioni in inglese solo dove serve.

Welcome to the **grammar** section! Here you'll find the main rules of Italian
with tables, examples and exercises with solutions. Every page is aimed at
**A2/B1** level, with short explanations in English only where needed.
