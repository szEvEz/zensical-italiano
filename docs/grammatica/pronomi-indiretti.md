# Pronomi indiretti

I **pronomi indiretti** sostituiscono il **complemento di termine**, cioè
*a + persona* (la domanda è *a chi?*). Indicano a chi è diretta l'azione, spesso con
verbi come *dare*, *dire*, *inviare*, *scrivere*, *telefonare*, *piacere*.

**Indirect object pronouns** replace the **indirect object**, that is **a** + person
(the question is **a chi?**, "to whom?"). They show who the action is directed at, often
with verbs like **dare** (to give), **dire** (to say), **inviare** (to send), **scrivere**
(to write), **telefonare** (to phone) and **piacere** (to please, used for "to like").
{: .en }

## Le forme

| Persona | Pronome indiretto | (= a …) |
|---|---|---|
| io | **mi** | a me |
| tu | **ti** | a te |
| lui (maschile) | **gli** | a lui |
| lei (femminile) | **le** | a lei |
| noi | **ci** | a noi |
| voi | **vi** | a voi |
| loro | **gli** | a loro |

!!! note "Nota"
    Come i pronomi diretti, anche gli indiretti si mettono **prima del verbo**:
    Io **gli** invio una lettera.

    Like direct object pronouns, indirect ones also go **before the verb**:
    **Io gli invio una lettera** (I send him a letter).
    {: .en }

## Come funziona

Il pronome indiretto sostituisce tutto il gruppo *a + persona*.
*The indirect object pronoun replaces the whole **a** + person group.*{ .en }

- Io invio una lettera **a Mario** → Io **gli** invio una lettera. *I send a letter to Mario → I send him a letter.*{ .en }
- Io invio una lettera **a Francesca** → Io **le** invio una lettera. *I send a letter to Francesca → I send her a letter.*{ .en }
- Luca invia una lettera **a me** → Luca **mi** invia una lettera. *Luca sends a letter to me → Luca sends me a letter.*{ .en }
- Luca invia una lettera **a te** → Luca **ti** invia una lettera. *Luca sends a letter to you → Luca sends you a letter.*{ .en }
- Luca invia una lettera **a me e a te** (a noi) → Luca **ci** invia una lettera. *Luca sends a letter to me and you (to us) → Luca sends us a letter.*{ .en }
- Luca invia una lettera **a te e ad Antonio** (a voi) → Luca **vi** invia una lettera. *Luca sends a letter to you and Antonio (to you all) → Luca sends you a letter.*{ .en }
- Luca invia una lettera **ai suoi genitori** (a loro) → Luca **gli** invia una lettera. *Luca sends a letter to his parents (to them) → Luca sends them a letter.*{ .en }

## Diretti o indiretti?

!!! warning "Attenzione alla differenza"
    Molte forme sono uguali (*mi, ti, ci, vi*), ma alla terza persona cambiano:
    *Many forms are the same (**mi, ti, ci, vi**), but in the third person they differ:*{ .en }

    | | diretto | indiretto |
    |---|---|---|
    | lui | **lo** | **gli** |
    | lei | **la** | **le** |
    | loro | **li / le** | **gli** |

    - Vedo **Mario** → **Lo** vedo. (chi? → diretto) *I see Mario → I see him. (who? → direct)*{ .en }
    - Scrivo **a Mario** → **Gli** scrivo. (a chi? → indiretto) *I write to Mario → I write to him. (to whom? → indirect)*{ .en }

    Vedi anche i [pronomi diretti](pronomi-diretti.md).
    *See also the [direct object pronouns](pronomi-diretti.md).*{ .en }

!!! tip "Trucco"
    Con l'indiretto il participio **non** concorda: Le ho scritto (a lei), non
    *le ho scritta*. La concordanza riguarda solo i pronomi diretti.

    With indirect pronouns the participle does **not** agree: **Le ho scritto** (a lei),
    "I wrote to her", not **le ho scritta**. Agreement only applies to direct object pronouns.
    {: .en }

## Esercizi

Sostituisci la parte in grassetto con il pronome indiretto giusto.
*Replace the part in bold with the correct indirect object pronoun.*{ .en }

1. Telefono **a mia madre**. → ______________ *I phone my mother.*{ .en }
2. Regalo un libro **a te**. → ______________ *I give a book to you (as a present).*{ .en }
3. Il professore spiega la regola **agli studenti**. → ______________ *The teacher explains the rule to the students.*{ .en }
4. Ho scritto una mail **a Francesca**. → ______________ *I wrote an email to Francesca.*{ .en }
5. Piace il gelato **a noi**? → ______________ piace il gelato? *Do we like ice cream?*{ .en }
6. Chiedo un favore **a voi**. → ______________ *I ask a favour of you (all).*{ .en }
7. Dico la verità **a Marco**. → ______________ *I tell Marco the truth.*{ .en }
8. Mando i saluti **a te e a Luca**. → ______________ *I send my regards to you and Luca.*{ .en }

??? success "Soluzioni"
    1. **Le** telefono.
    2. **Ti** regalo un libro.
    3. **Gli** spiega la regola.
    4. **Le** ho scritto una mail.
    5. **Ci** piace il gelato?
    6. **Vi** chiedo un favore.
    7. **Gli** dico la verità.
    8. **Vi** mando i saluti.
