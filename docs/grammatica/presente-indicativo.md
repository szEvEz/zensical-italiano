# Presente indicativo

Il **presente indicativo** descrive azioni che avvengono adesso, azioni abituali
e verità generali. In italiano i verbi si dividono in tre gruppi (coniugazioni):
**-are**, **-ere**, **-ire**.

The **present indicative** describes actions happening now, habitual actions
and general truths. In Italian, verbs are divided into three groups (conjugations):
**-are**, **-ere**, **-ire**.
{: .en }

## Quando si usa

- **Azione nel presente** → Adesso **studio** italiano. *Action in the present → I'm studying Italian now.*{ .en }
- **Abitudine** → Ogni giorno **lavoro** dalle 9 alle 17. *Habit → Every day I work from 9 to 5.*{ .en }
- **Verità generale** → L'acqua **bolle** a 100 gradi. *General truth → Water boils at 100 degrees.*{ .en }
- **Futuro programmato** → Domani **parto** per Roma. *Planned future → Tomorrow I'm leaving for Rome.*{ .en }

## Verbi regolari

| | parl**are** | prend**ere** | dorm**ire** |
|---|---|---|---|
| io | parl**o** | prend**o** | dorm**o** |
| tu | parl**i** | prend**i** | dorm**i** |
| lui/lei | parl**a** | prend**e** | dorm**e** |
| noi | parl**iamo** | prend**iamo** | dorm**iamo** |
| voi | parl**ate** | prend**ete** | dorm**ite** |
| loro | parl**ano** | prend**ono** | dorm**ono** |

!!! note "Nota"
    Altri verbi regolari in **-ere** funzionano come *prendere*: *scrivere*
    (scriv**o**, scriv**i**, scriv**e**, scriv**iamo**, scriv**ete**, scriv**ono**),
    *leggere*, *vedere*, *chiedere*.

    Other regular **-ere** verbs work like **prendere**: **scrivere**
    (scriv**o**, scriv**i**, scriv**e**, scriv**iamo**, scriv**ete**, scriv**ono**),
    **leggere**, **vedere**, **chiedere**.
    {: .en }

### Verbi in **-ire** con **-isc-**

Molti verbi in *-ire* aggiungono **-isc-** alle persone io, tu, lui/lei, loro.
Esempio: **capire** (*to understand*).

Many **-ire** verbs add **-isc-** in the io, tu, lui/lei and loro forms.
Example: **capire** (*to understand*).
{: .en }

| | cap**ire** |
|---|---|
| io | cap**isc**o |
| tu | cap**isc**i |
| lui/lei | cap**isc**e |
| noi | cap**iamo** |
| voi | cap**ite** |
| loro | cap**isc**ono |

!!! tip "Trucco"
    Altri verbi come *capire*: **finire**, **preferire**, **pulire**, **spedire**,
    **costruire**. Le persone *noi* e *voi* restano regolari (senza -isc-).

    Other verbs like **capire**: **finire**, **preferire**, **pulire**, **spedire**,
    **costruire**. The **noi** and **voi** forms stay regular (no -isc-).
    {: .en }

## Il verbo *piacere*

Il verbo **piacere** (*to please, to be liked*) funziona in modo particolare: il soggetto è la
cosa che piace, non la persona.

The verb **piacere** (*to please, to be liked*) works in a special way: the subject is the
thing that is liked, not the person.
{: .en }

- **Mi piace** + nome singolare o infinito → Mi piace **il caffè**. / Mi piace **leggere**. *With a singular noun or an infinitive, use **mi piace** → I like coffee. / I like reading.*{ .en }
- **Mi piacciono** + nome plurale → Mi piacciono **i gatti**. *With a plural noun, use **mi piacciono** → I like cats.*{ .en }

!!! warning "Attenzione"
    Si dice *mi piace la pizza* (I like pizza — literally: pizza pleases me), non ~~io piaccio la pizza~~.
    Con più cose si usa **piacciono**: *mi piacciono le lingue*.

    You say **mi piace la pizza** (I like pizza — literally: pizza pleases me), not ~~io piaccio la pizza~~.
    With more than one thing you use **piacciono**: **mi piacciono le lingue** (I like languages).
    {: .en }

## Esercizi

Coniuga il verbo tra parentesi al presente indicativo.

Conjugate the verb in brackets in the present indicative.
{: .en }

1. Io (parlare) ___ italiano e tedesco. *I speak Italian and German.*{ .en }
2. Tu (prendere) ___ un caffè? *Are you having a coffee?*{ .en }
3. Marco (dormire) ___ fino a tardi. *Marco sleeps in late.*{ .en }
4. Noi non (capire) ___ questa frase. *We don't understand this sentence.*{ .en }
5. Voi (andare) ___ al cinema stasera? *Are you going to the cinema tonight?*{ .en }
6. Loro (fare) ___ i compiti. *They're doing their homework.*{ .en }
7. Io (uscire) ___ con gli amici. *I'm going out with my friends.*{ .en }
8. Tu (volere) ___ un gelato? *Do you want an ice cream?*{ .en }
9. A me (piacere) ___ la musica classica. *I like classical music.*{ .en }
10. A te (piacere) ___ i film d'azione. *You like action films.*{ .en }
