# Futuro anteriore

Il **futuro anteriore** (*future perfect*) indica un'azione futura che sarà **conclusa
prima** di un'altra azione futura. In inglese corrisponde a *I will have eaten*.

The **futuro anteriore** (*future perfect*) expresses a future action that will be **completed
before** another future action. In English it corresponds to *I will have eaten*.
{: .en }

## Come si forma

**Futuro semplice di _essere_ o _avere_** + **participio passato**.

**Simple future of essere or avere** + **past participle**.
{: .en }

| Ausiliare | Esempio (io) |
|---|---|
| avere → avrò | io **avrò mangiato** |
| essere → sarò | io **sarò andato/a** |

### Futuro semplice degli ausiliari

| | *avere* | *essere* |
|---|---|---|
| io | avrò | sarò |
| tu | avrai | sarai |
| lui/lei | avrà | sarà |
| noi | avremo | saremo |
| voi | avrete | sarete |
| loro | avranno | saranno |

!!! note "Accordo con *essere*"
    Come nel [passato prossimo](passato-prossimo.md), con **essere** il participio
    si accorda con il soggetto: *sarò andato / andata*, *saremo partiti / partite*.

    As in the [passato prossimo](passato-prossimo.md), with **essere** the participle
    agrees with the subject: *sarò andato / andata*, *saremo partiti / partite*.
    {: .en }

## Quando si usa

- **Azione futura conclusa prima di un'altra** azione futura:
  → Quando **avrò finito** i compiti, **mangerò** un gelato.
  (When I've finished my homework, I'll have an ice cream.) *A future action completed before another future action.*{ .en }
- **Supposizione sul passato** (uso più raro):
  → Non risponde: **sarà uscito**. (He's not answering: he must have gone out.) *A guess about the past (less common use).*{ .en }

!!! tip "Mini-timeline"
    ```
    ADESSO ──────► [avrò finito i compiti] ──────► [mangerò un gelato] ─► FUTURO
                     (azione 1: prima)              (azione 2: dopo)
    ```
    Prima si conclude l'azione al **futuro anteriore**, poi avviene l'azione al
    **futuro semplice**.

    First the action in the **futuro anteriore** is completed, then the action in the
    **simple future** takes place.
    {: .en }

## Esempi

- Quando **avrò finito** i compiti, **mangerò** un gelato. *When I've finished my homework, I'll have an ice cream.*{ .en }
- Dopo che **saremo arrivati**, ti **chiameremo**. *Once we've arrived, we'll call you.*{ .en }
- Appena **avrai letto** il libro, me lo **presterai**. *As soon as you've read the book, you'll lend it to me.*{ .en }
- Quando **sarà tornata** Maria, **ceneremo** insieme. *When Maria is back, we'll have dinner together.*{ .en }

## Esercizi

Coniuga il verbo tra parentesi al futuro anteriore.

Conjugate the verb in brackets in the futuro anteriore.
{: .en }

1. Quando io (finire) ___ di lavorare, uscirò. *When I've finished work, I'll go out.*{ .en }
2. Dopo che tu (mangiare) ___, laveremo i piatti. *After you've eaten, we'll do the dishes.*{ .en }
3. Appena loro (arrivare) ___, cominceremo la festa. *As soon as they've arrived, we'll start the party.*{ .en }
4. Quando noi (leggere) ___ il libro, ne parleremo. *When we've read the book, we'll talk about it.*{ .en }
5. Dopo che lei (partire) ___, chiuderò la casa. *After she has left, I'll lock up the house.*{ .en }
6. Appena voi (fare) ___ i compiti, potrete giocare. *As soon as you've done your homework, you can play.*{ .en }

??? success "Soluzioni"
    1. avrò finito
    2. avrai mangiato
    3. saranno arrivati
    4. avremo letto
    5. sarà partita
    6. avrete fatto
