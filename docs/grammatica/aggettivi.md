# Aggettivi qualificativi

Gli aggettivi qualificativi descrivono un nome (una cosa, una persona). In italiano l'aggettivo **si accorda** (agrees) con il nome in **genere** (maschile/femminile) e **numero** (singolare/plurale).

Descriptive adjectives describe a noun (a thing, a person). In Italian the adjective **agrees** with the noun in **gender** (masculine/feminine) and **number** (singular/plural).
{: .en }

## Accordo dell'aggettivo

### Aggettivi in -o (4 forme)

Questi aggettivi hanno quattro forme: **-o / -a / -i / -e**.
*These adjectives have four forms: **-o / -a / -i / -e**.*{ .en }

| | Singolare | Plurale |
|-----------|-----------|---------|
| Maschile  | alt**o**  | alt**i** |
| Femminile | alt**a**  | alt**e** |

Esempi: un ragazzo alt**o**, una ragazza alt**a**, i ragazzi alt**i**, le ragazze alt**e**.
*Examples: a tall boy, a tall girl, the tall boys, the tall girls.*{ .en }

### Aggettivi in -e (2 forme)

Questi aggettivi hanno solo due forme: **-e** (singolare) / **-i** (plurale). Non cambiano tra maschile e femminile.

These adjectives have only two forms: **-e** (singular) / **-i** (plural). They don't change between masculine and feminine.
{: .en }

| | Singolare | Plurale |
|-----------|-----------|---------|
| Maschile  | grand**e** | grand**i** |
| Femminile | grand**e** | grand**i** |

Esempi: un libro grand**e**, una casa grand**e**, i libri grand**i**, le case grand**i**.
*Examples: a big book, a big house, the big books, the big houses.*{ .en }

!!! note "Nota"
    L'aggettivo in italiano di solito segue il nome: *una macchina rossa* (non *una rossa macchina*).
    *In Italian the adjective usually comes after the noun: **una macchina rossa** (a red car), not **una rossa macchina**.*{ .en }

## Superlativo assoluto

Il superlativo assoluto indica una qualità al massimo grado, senza confronto. Significa **"molto + aggettivo"**.

The absolute superlative expresses a quality to the highest degree, without any comparison. It means **"molto + adjective"** ("very + adjective").
{: .en }

Si forma togliendo l'ultima vocale e aggiungendo **-issimo / -issima / -issimi / -issime**.
*It's formed by dropping the last vowel and adding **-issimo / -issima / -issimi / -issime**.*{ .en }

- bella → **bellissima** (= molto bella) *beautiful → very beautiful*{ .en }
- alto → **altissimo** (= molto alto) *tall → very tall*{ .en }
- grande → **grandissimo** (= molto grande) *big → very big*{ .en }
- veloci → **velocissimi** (= molto veloci) *fast → very fast*{ .en }

!!! tip "Trucco"
    Il superlativo assoluto si accorda come un normale aggettivo in -o: bell**issimo** / bell**issima** / bell**issimi** / bell**issime**.
    *The absolute superlative agrees like a normal adjective in -o: **bellissimo / bellissima / bellissimi / bellissime**.*{ .en }

## Esercizio A — Scrivi l'opposto

1. alto → ___
2. triste → ___
3. nuovo → ___
4. lento → ___
5. facile → ___

??? success "Soluzioni"
    1. basso
    2. felice / allegro
    3. vecchio
    4. veloce
    5. difficile
