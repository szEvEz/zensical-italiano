# Prenotazioni e viaggi

Frasi utili per organizzare un viaggio: comprare biglietti, affittare un appartamento e prenotare al ristorante.

Useful phrases for organising a trip: buying tickets, renting a flat and booking a restaurant.
{: .en }

## Comprare un biglietto del treno

- Vorrei un biglietto per… il prima possibile. *I'd like a ticket to… as soon as possible.*{ .en }
- Da quale binario parte il treno? *Which platform does the train leave from?*{ .en }
- Devo obliterare il biglietto? *Do I have to validate the ticket?*{ .en }

!!! tip "Frase utile"
    **Obliterare** il biglietto significa timbrarlo/convalidarlo prima di salire (per alcuni biglietti regionali). In inglese: *to validate the ticket*.

    To **obliterare** a ticket means to stamp/validate it before boarding (required for some regional tickets).
    {: .en }

## Affittare un appartamento (Airbnb)

- Vorrei affittare un appartamento a Milano dal 15 al 25 agosto. *I'd like to rent a flat in Milan from 15 to 25 August.*{ .en }
- In una zona centrale o facilmente raggiungibile dal centro. *In a central area or one that's easy to reach from the centre.*{ .en }
- La zona è tranquilla di notte? *Is the area quiet at night?*{ .en }
- Ci sono buoni ristoranti in zona? *Are there good restaurants in the area?*{ .en }
- C'è il wifi? Com'è il wifi? *Is there Wi-Fi? How good is the Wi-Fi?*{ .en }
- C'è l'aria condizionata / il riscaldamento? *Is there air conditioning / heating?*{ .en }
- C'è una lavatrice? *Is there a washing machine?*{ .en }
- La cucina è attrezzata? *Is the kitchen fully equipped?*{ .en }
- Come arrivo al Duomo dall'appartamento? *How do I get to the Duomo from the flat?*{ .en }

## Comprare un biglietto aereo

- Vorrei comprare un biglietto per il Vietnam, partenza da Milano e arrivo a Ho Chi Minh, dal 25 gennaio al 15 febbraio. *I'd like to buy a ticket to Vietnam, departing from Milan and arriving in Ho Chi Minh City, from 25 January to 15 February.*{ .en }
- Vorrei scegliere il posto. *I'd like to choose my seat.*{ .en }
- Preferisco vicino al finestrino (o corridoio). *I'd prefer a window seat (or an aisle seat).*{ .en }
- Il bagaglio a mano è incluso? *Is hand luggage included?*{ .en }
- Sono inclusi i pasti? *Are meals included?*{ .en }

## Prenotare al ristorante

- Vorrei prenotare un tavolo per due persone alle 20. *I'd like to book a table for two at 8 p.m.*{ .en }

!!! note "Attenzione al condizionale"
    Molte di queste richieste usano il [condizionale presente](../grammatica/condizionale-presente.md) (*Vorrei…*), che rende la domanda più educata rispetto al presente (*Voglio…*).

    Many of these requests use the [present conditional](../grammatica/condizionale-presente.md) (*Vorrei…*), which makes the question more polite than the present tense (*Voglio…*).
    {: .en }
