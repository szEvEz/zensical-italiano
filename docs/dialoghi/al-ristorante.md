# Al ristorante

**Cameriere:** Ciao, benvenuto! Sei da solo o aspetti qualcuno?
*Hi, welcome! Are you on your own or waiting for someone?*{ .en }

**Cliente:** Ciao! Sono da solo.
*Hi! I'm on my own.*{ .en }

**Cameriere:** Ok, se vuoi puoi accomodarti qui vicino alla finestra.
*OK, if you like you can sit here by the window.*{ .en }

**Cliente:** Perfetto, grazie.
*Perfect, thanks.*{ .en }

**Cameriere:** Ti porto subito il menù. Vuoi già bere qualcosa?
*I'll bring you the menu right away. Would you like something to drink already?*{ .en }

**Cliente:** Sì, magari solo un'acqua naturale per adesso.
*Yes, maybe just a still water for now.*{ .en }

**Cameriere:** Va bene, arrivo subito.
*All right, I'll be right back.*{ .en }

*(dopo poco)* *(shortly after)*{ .en }

**Cameriere:** Ecco l'acqua e il menù. Se hai domande, chiedi pure.
*Here's the water and the menu. If you have any questions, just ask.*{ .en }

**Cliente:** Grazie. Sto dando un'occhiata… cosa mi consigli?
*Thanks. I'm having a look… what do you recommend?*{ .en }

**Cameriere:** Dipende da cosa ti piace. La pasta del giorno è con pomodorini, burrata e basilico fresco. Oppure abbiamo un'insalata con pollo grigliato che va forte.
*It depends on what you like. The pasta of the day comes with cherry tomatoes, burrata and fresh basil. Or we have a grilled chicken salad that's very popular.*{ .en }

**Cliente:** Allora prendo la pasta. Mi hai convinto.
*Then I'll have the pasta. You've convinced me.*{ .en }

**Cameriere:** Ottimo! Vuoi anche del pane?
*Great! Would you like some bread too?*{ .en }

**Cliente:** Sì, grazie.
*Yes, please.*{ .en }

*(dopo aver mangiato)* *(after eating)*{ .en }

**Cameriere:** Tutto bene?
*Is everything all right?*{ .en }

**Cliente:** Sì, era buonissima. Complimenti!
*Yes, it was delicious. My compliments!*{ .en }

**Cameriere:** Mi fa piacere. Vuoi un dolce o un caffè?
*I'm glad. Would you like a dessert or a coffee?*{ .en }

**Cliente:** Un caffè, per favore.
*A coffee, please.*{ .en }

**Cameriere:** Subito.
*Right away.*{ .en }

*(dopo il caffè)* *(after the coffee)*{ .en }

**Cliente:** Posso avere il conto, per favore?
*Can I have the bill, please?*{ .en }

**Cameriere:** Certo, arrivo subito. *(torna con il conto)* Sono 16 euro.
*Of course, I'll be right there. (comes back with the bill) That's 16 euros.*{ .en }

**Cliente:** Ecco a te.
*Here you go.*{ .en }

**Cameriere:** Grazie! Buona giornata e magari alla prossima!
*Thanks! Have a nice day, and see you next time maybe!*{ .en }

**Cliente:** Volentieri, ciao!
*Gladly, bye!*{ .en }

## Frasi utili

- **Posso avere il conto, per favore?** — Can I have the bill, please?
- **Cosa mi consigli?** — What do you recommend? (formale: *Cosa mi consiglia?*)
- **Vorrei…** — I'd like… (forma cortese per ordinare)
- **un'acqua naturale / frizzante** — a still / sparkling water
- **Va forte** — è molto richiesto, piace a tanti (it's very popular, it sells well)

!!! tip "Frase utile"
    Per ordinare in modo educato usa **Vorrei…** invece di *Voglio…*: suona molto più gentile.
    *To order politely, use **Vorrei…** instead of **Voglio…**: it sounds much nicer.*{ .en }
